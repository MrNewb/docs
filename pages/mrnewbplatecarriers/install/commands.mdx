# Commands

| Command | Where | What it does |
| --- | --- | --- |
| `/removevest` | in-game | Unequip the carrier back to inventory. Also keybound — shipped default `O` (`Config.RegisteredKeyMapping`) |
| `/removehelmet` | in-game | Unequip the helmet back to inventory |
| `/inspectvest` | in-game | Open the equipped-carrier plate menu (same as `OpenPlateCarrierMenu`) |

No admin or console commands. Progress is blocked when the matching `Config.Settings.Gates` flag is true (vehicle, swimming, dead, cuffed).
