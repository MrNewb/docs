# Item images

Copy `giftbox.png` from `[INSTALL]/` into your inventory images folder. One PNG covers the shipped `starter_box` and `gang_kit` items (and any extra boxes you point at the same file).

| Inventory | Destination |
| --- | --- |
| ox_inventory | `ox_inventory/web/images/` |
| qb-inventory / ps-inventory | `html/images/` |
| one_inventory | `one_inventory/web/images/` |

| Item | File |
| --- | --- |
| Starter box / gang kit (shared art) | `giftbox.png` |
