# MrNewbBeeKeeping

Player-owned beekeeping: place hives, manage queens and workers, harvest regional honey, sell at the shop, and catch wild swarms. Built on [Newb_Bridge](/newb_bridge).

## Requirements

- [Newb_Bridge](/newb_bridge)
- ox_lib, oxmysql
- Artifact `/server:6116` or newer, OneSync
- Compatible inventory (ox_inventory recommended)
- Hive props ship in `stream/` (`jim_g_beehive_prop.ytyp` is registered in `fxmanifest.lua`)

Keep the folder named `MrNewbBeeKeeping`. Most Lua is escrowed; `configs/`, `locales/`, and `resource/open/` stay editable. Do **not** add `server.export` on ox_inventory items — use is registered with `bridge.framework.registerItemUse`.

## Features

- Place and own hives with a personal cap, optional VIP extras, and owner or allowlist access
- Production loop — workers make honey and wax; queen health and genetics change output. An **open** hive does not tick
- Seven regional honeys (blue, green, red, amber, lavender, citrus, wildflower) plus default wild honey
- Queen genetics — trait strains, zone modifiers, breeding cells, in-game strain guide
- Wild swarms — particles, sting damage, trap catches, optional respawn
- Beekeeper suit — blocks swarm stings while worn
- Beekeeper shop — buy supplies, sell honey and wax (`PayTo` is `bank` or `cash`)
- Admin NUI (`/HiveAdmin`) — hive list and access, map blips, delete, owner/stale wipe, grant queens, strain builder

## Player loop

1. Buy a `beehive`, workers, and a queen from the shop (or catch workers / a rare queen from a wild swarm with a `bee_trap`)
2. Use the hive item to place it on whitelisted ground outside blacklist zones
3. Open the colony, install the queen, add workers — production only runs while the hive is **closed**
4. Extract honey (minigame) and wax when stores fill; sell at the shop
5. Optional: raise a daughter queen from a breeding cell, smoke the hive, wear the suit near swarms, read the strain guide

Staff open `/HiveAdmin` for inventory, map blips, maintenance wipes, strain grants, and the strain builder (writes to `created_strains.txt`).

## Where you edit

| File | What it does |
| --- | --- |
| `configs/config.lua` | Client-visible: hives, minigames, placement, swarms, trap, suit, honey types, shops, props, particles |
| `configs/genetics.lua` | Strain labels, breeding gates, `StrainGuideItem`, default trait |
| `configs/placement.lua` | Blacklist polygons and placeable ground material hashes |
| `configs/sv_config.lua` | Admin/VIP, hive cap, colony rates, shop prices, honey zone polygons, `traitStats` |
| `resource/open/client/custom.lua` | Suit clothing hooks, minigame fail / prop attach skips |
| `resource/open/server/custom.lua` | Queen trait roll, honey reward item, trap catch hook |
| `resource/open/client/minigames.lua` | Honey extraction minigame backends |
| `locales/*.json` | Player and admin copy (shipped multilanguage) |
| `[INSTALL]/imgs/` | Inventory PNGs |
| `[INSTALL]/ox_inventory_items.txt` | Paste-ready ox_inventory item defs |

Shop location `id` values in `config.lua` must match an `ItemsForSale` key in `sv_config.lua` (shipped: `newb_beekeeper_shop`). Prices, caps, VIP, and trait multipliers stay server-only. Restart after config or item changes.

| `Config.Shops.Locations` | Ped shops (`id` must match `ItemsForSale`) |

### `configs/sv_config.lua` (highlights)

| Key | Purpose |
| --- | --- |
| `Config.IsHiveAdmin(src)` | Who can open `/HiveAdmin` (default `bridge.framework.isAdmin`) |
| `Config.IsPlayerHiveVip(src)` | VIP check (default ACE `mrnewb.vip`) |
| `Config.Hives.MaxHivesPerPlayer` | Personal cap (`0` = unlimited) |
| `Config.Vip` | `Enabled`, `ExtraHives`, `VipPlayers` list |
| `Config.Maintenance` | Wipe hives for inactive owners |
| `Config.Colony.MinutesPerProductionTick` | Main economy dial (lower = faster) |
| `Config.Colony.MaxHoneyPerHive` / `MaxWaxPerHive` / `MaxWorkerBeesPerHive` | Storage caps; full honey stalls production |
| `Config.Shops.PayTo` | `'bank'` or `'cash'` for sales |
| `Config.Shops.WaxSellPrice` / `HoneySellPrices` | Sell payouts |
| `Config.Shops.ItemsForSale` | Buy stock per shop id |
| `Config.ZoneTypes` | Honey region polygons (z ignored) |
| `traitStats` (local table) | Strain multipliers folded onto `Config.BeeGenetics.Traits` |

### Genetics

`configs/genetics.lua` holds player-facing labels and breeding requirements. Yields, rarity, roll zones, and `manualOnly` live in the `traitStats` block at the bottom of `sv_config.lua` so clients cannot read them. Every trait id needs an entry in **both** places. The admin Strain Builder appends matching blocks to `created_strains.txt` for you to paste.

## Persistence

The SQL table `mrnewb_beekeeping` is created on start — there is no `.sql` file to import.

Coming from an older MrNewbBeeKeeping? Hive rows in that table are converted automatically on start if they are still in the old format. The server console prints when it happens; restart the server after you see that message. If the data is already current, nothing extra runs.

Config keys are not converted. Use the rename table below if you still have a v1 config.

## Config migration (v1 to v2)

Breaking renames. There are **no** runtime aliases — update your configs if you are coming from an older build.

| Old | New |
| --- | --- |
| `Config.Utility` | `Config.General` |
| `Config.HiveMaintenanceSettings` | `Config.Maintenance` (now in `sv_config.lua`) |
| `Config.PlayerHiveSettings` | `Config.Hives` |
| `Config.VipHiveLimits` | `Config.Vip` |
| `Config.HoneySettings` / `WaxSettings` / `WorkerSettings` / `HiveGameplaySettings` | `Config.Colony` |
| `Config.HivePlacementSettings` | `Config.Placement` |
| `Config.BeeSwarms` | `Config.WildSwarms` |
| `Config.HoneyVariants` / `HoneyZonePriority` | `Config.HoneyTypes` |
| `Config.ShopSettings` | `Config.Shops` |
| `configs/sv_economy.lua` / `configs/sv_zones.lua` | Merged into `configs/sv_config.lua` |

Hive models are `Config.Hives.ClosedModel` / `OpenModel` and `Config.Props` (not a separate `BeeKeepingModels` table).

## Exports

| Export | Returns |
| --- | --- |
| `IsPlayerHiveVip(src)` | Whether VIP extras apply (requires `Vip.Enabled`, and the player at the base cap) |
| `GetPlayerHiveBonusHives(src)` | Extra slots, or `0` |
| `GetPlayerHiveLimit(src)` | Personal cap. **`-1`** when `MaxHivesPerPlayer` is `0` (unlimited) |
| `IsPlayerAtHiveLimit(src)` | Whether owned hives are at that personal cap |

```lua
exports.MrNewbBeeKeeping:GetPlayerHiveLimit(source)
```

Details and open hooks: [Server exports](/mrnewbbeekeeping/exports/server-exports).
