## Newb_Bridge quick facts

- Resource name: `Newb_Bridge`
- Required dependency: `ox_lib`
- Import in fxmanifest: `@Newb_Bridge/import.lua` exposes global `bridge`
- Modules lazy-load on first access (`bridge.inventory`, `bridge.framework`, etc.)
- Configure providers in `settings/bridge_resources.lua` or use `"auto"`
- LuaLS types: `Newb_Bridge/types/types.lua`
- Server notifications: `bridge.notifications.notify(src, data)` not `bridge.framework.notify`
- Inventory add/remove order: `metadata` before `slot` (differs from community_bridge)

### Minimal setup

```lua
-- fxmanifest.lua
shared_scripts {
    '@ox_lib/init.lua',
    '@Newb_Bridge/import.lua',
}
```

```cfg
ensure ox_lib
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory
ensure Newb_Bridge
ensure your_script
```

## exports.Newb_Bridge

- `GetConfig()` — bridge Config table
- `Dialogue()` — dialogue API (client)
- `PropPlacer(model, forceGround?, allowedMaterials?, maxDistance?)` — client placement, returns vector4 or nil
- `CreateZone(options)` — client zone creator, returns ox_lib zone table or nil
- `useGizmo(entity)` — client gizmo editor
- `AddInteraction(id, payload)` — client world ped/prop spawner with target
- `RemoveInteraction(id)` — client or server (server broadcasts)
- `UpdateInteraction(id, updates)` — client
- `RemoveAllInteractions()` — client
- `GetClosestInteraction()` — client, no args
- `GetNearbyInteractions()` — client, no args
- `VersionCheck(repoPath, resourceName)` — server GitHub version check

## Lifecycle events

- `Newb_Bridge:server:playerLoad` (src)
- `Newb_Bridge:server:playerUnload` (src)
- `Newb_Bridge:server:playerJobUpdate` (src, jobName)
- `Newb_Bridge:client:playerLoad`
- `Newb_Bridge:client:playerUnload`
- `Newb_Bridge:client:playerJobUpdate` (jobName, jobLabel, gradeName, gradeLevel)
- `Newb_Bridge:client:zoneCreatorEnteredFreecam` (data table)
- `Newb_Bridge:client:zoneCreatorExitedFreecam` (data table)

## community_bridge migration

| Old | New |
|-----|-----|
| `exports.community_bridge:Bridge()` | `@Newb_Bridge/import.lua` → `bridge` |
| `community_bridge:Server:OnPlayerLoaded` | `Newb_Bridge:server:playerLoad` |
| `community_bridge:Client:OnPlayerUnload` | `Newb_Bridge:client:playerUnload` |
| `Bridge.Inventory.RemoveItem(src, item, count, slot, metadata)` | `bridge.inventory.removeItem(src, item, count, metadata, slot)` |
