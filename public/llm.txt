# MrNewb Documentation

> Official docs for MrNewb FiveM scripts: install order, item setup, config, and public exports.
> Live site: https://mrnewb.github.io/docs (`basePath` `/docs`)
> Docs source: https://github.com/MrNewb/docs
> Scripts org: https://github.com/MrNewb
> Tebex: https://mrnewbscripts.tebex.io/
> Discord: https://discord.gg/mrnewbscripts

This file is a machine-readable index plus the facts an assistant needs to answer install and API questions without inventing internals. Prefer the published page URLs below as canonical. Match resource folder names, parameter order, and client vs server exactly.

## How to answer from this site

- Most MrNewb scripts import `@Newb_Bridge/import.lua` (global `bridge`) and start **after** `ox_lib`, the framework, inventory/target, and `Newb_Bridge`.
- Do **not** invent `Resource:Server:` net events or `Resource:Callback:` names. Those are internal. Public integration is exports, `resource/open/` hooks, and the events listed here.
- Documented hook events: `Newb_Bridge:*` lifecycle / task-group / utility events, and `MrNewbNameChanger:Server:NameChanged` (`AddEventHandler` only).
- Folder name must match the `ensure` / `exports.` name. Docs slugs are lowercase without underscores except Newb_Bridge (`/newb_bridge`). Spooky folder is `MrNewbsSpookySeason` (extra `s`); docs slug is `/mrnewbspookyseason`.
- TacoLink was renamed to Newb_Bridge. Same `bridge.*` API.
- Do not invent paid/free status, download counts, or Gitbook URLs. Retired Gitbook is not canonical. GitHub Pages host is `mrnewb.github.io`, **not** `mrnewbscripts.github.io`.

- [Landing](https://mrnewb.github.io/docs/newb_bridge)
- [Installation](https://mrnewb.github.io/docs/newb_bridge/getting-started): start **after** framework / inventory / target; scripts that import the bridge start **after** Newb_Bridge
- [Configuration](https://mrnewb.github.io/docs/newb_bridge/configuration): `settings/bridge_resources.lua`
- [Supported](https://mrnewb.github.io/docs/newb_bridge/supported): provider tables (auto / manual / fallback)
- [Resource layout](https://mrnewb.github.io/docs/newb_bridge/developers/resource-layout)
- [Modules](https://mrnewb.github.io/docs/newb_bridge/developers/modules)
- [Utilities](https://mrnewb.github.io/docs/newb_bridge/developers/utilities): `exports.Newb_Bridge`
- [Events](https://mrnewb.github.io/docs/newb_bridge/developers/events)
- [Migrating](https://mrnewb.github.io/docs/newb_bridge/developers/migrating): community_bridge → Newb_Bridge

### Import and start order

```lua
-- consuming resource fxmanifest.lua
shared_scripts {
    '@ox_lib/init.lua',
    '@Newb_Bridge/import.lua',
}
```

```cfg
ensure ox_lib
ensure oxmysql
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory
ensure ox_target
ensure Newb_Bridge
ensure your_script
```

Leave providers on `"auto"` unless pinning. `Config.Dispatch` defaults to `"internal"`, not `"auto"`. Modules lazy-load on first `bridge.*` access. Missing providers become a quiet noop table. `bridge.dialogue` and `bridge.task` error if accessed on the server. `bridge.dispatch` and `bridge.bossmenu` are host-only on the client.

LuaLS types: `Newb_Bridge/types/types.lua`. Server notify is `bridge.notifications.notify(src, data)`, not `bridge.framework.notify`. Inventory add/remove: `metadata` before `slot` (differs from community_bridge). Server money: `getMoney` / `addMoney` / `removeMoney`. Client `getAccountBalance` is display-only.

### exports.Newb_Bridge

- `GetConfig()` — bridge Config table
- `Dialogue()` — dialogue API (client)
- `PropPlacer(model, forceGround?, allowedMaterials?, maxDistance?)` — client placement, returns vector4 or nil
- `CreateZone(options)` — client zone creator, returns ox_lib zone table or nil
- `useGizmo(entity)` — client gizmo editor
- `AddInteraction(id, payload)` — client world ped/prop with target; `radius` default 100, clamped 1–175; existing id is replaced
- `RemoveInteraction(id, target?)` — client local; server broadcasts (or one player if `target` is a source; bad target does not fall back to broadcast)
- `UpdateInteraction(id, updates)` — client
- `RemoveAllInteractions()` — client
- `GetClosestInteraction()` — client, no args
- `GetNearbyInteractions()` — client, no args
- `VersionCheck(repoPath, resourceName)` — server GitHub version check

### Lifecycle events (AddEventHandler; host emits)

- `Newb_Bridge:server:playerLoad` (`src`)
- `Newb_Bridge:server:playerUnload` (`src`)
- `Newb_Bridge:server:playerJobUpdate` (`src`, `jobName`)
- `Newb_Bridge:client:playerLoad` (no payload)
- `Newb_Bridge:client:playerUnload`
- `Newb_Bridge:client:playerJobUpdate` (`jobName`, `jobLabel`, `gradeName`, `gradeLevel`) — also on duty change
- `Newb_Bridge:client:zoneCreatorEnteredFreecam` / `ExitedFreecam` (poly zones only)

Do not re-register `Newb_Bridge:client:notify` if you already call `bridge.notifications.notify` — that double-fires. Task-group server events live on the taskgroups server page.

## BeeKeeping (`MrNewbBeeKeeping`)

Place hives, queens/workers, regional honey, honey separator, shop, wild swarms. Needs Newb_Bridge, ox_lib, oxmysql, inventory. Settings are in the `/hivesetup` panel. An **open** hive does not tick. 18 items. Props in `stream/` (`mrnewb_beekeeping.ytyp`).

- [Landing](https://mrnewb.github.io/docs/mrnewbbeekeeping)
- [Install](https://mrnewb.github.io/docs/mrnewbbeekeeping/install)
- [Commands](https://mrnewb.github.io/docs/mrnewbbeekeeping/install/commands): `/hivesetup [hiveId]`; `/staffdebug` and `/reloadhives` only when Debug is on in the panel
- [Configuration](https://mrnewb.github.io/docs/mrnewbbeekeeping/install/configuration)
- [Anticheat models](https://mrnewb.github.io/docs/mrnewbbeekeeping/anticheat): standard hives `jim_g_beehive_prop_2` / `_3`, rustic `mrnewb_hive_closed` / `mrnewb_hive_open`, trap, honeycomb, separator crank and motor
- [Item setup](https://mrnewb.github.io/docs/mrnewbbeekeeping/install/inventory)
- [Item images](https://mrnewb.github.io/docs/mrnewbbeekeeping/install/inventory-images)
- [Server exports](https://mrnewb.github.io/docs/mrnewbbeekeeping/exports/server-exports)
- [Client exports](https://mrnewb.github.io/docs/mrnewbbeekeeping/exports/client-exports): separator prop helpers

Exports: `IsPlayerHiveVip(src)`, `GetPlayerHiveBonusHives(src)`, `GetPlayerHiveLimit(src)` (`-1` = unlimited), `IsPlayerAtHiveLimit(src)`. VIP is false until the player is at the base cap, and never applies when the base cap is `0`.

Open hooks: `RollQueenTrait`, `ResolveHoneyRewardItem`, `OnTrapCatch`, `Config.IsHiveAdmin` (`open/server/custom.lua`); suit / minigame hooks (`open/client/custom.lua`). Public client event: `MrNewbBeeKeeping:Client:OpenStrainGuide`. SQL: `mrnewb_beekeeping`, separator tables, `mrnewb_beekeeping_traps`. No SQL file to import.

Walk-up jobs, bank-paid ID replacement (`um-idcard` / `bl_idcard` / `id_card` item), applications + optional Discord webhooks. Newb_Bridge, ox_lib. **No oxmysql. No shipped items. No exports.**

- [Landing](https://mrnewb.github.io/docs/mrnewbcityhall)

ESX / QB / Qbox only. **No exports, no commands, no SQL import** — updates the framework vehicle table in place. Keys: `bridge.vehiclekeys.remove` then `give`.

- [Landing](https://mrnewb.github.io/docs/mrnewbcustomplates)

## LootTables (`MrNewbLootTables`)

Other resources call the rolls. Config is **server-only**. Needs ox_lib + Newb_Bridge.

- [Landing](https://mrnewb.github.io/docs/mrnewbloottables)
- [Install](https://mrnewb.github.io/docs/mrnewbloottables/install)
- [Exports](https://mrnewb.github.io/docs/mrnewbloottables/exports)
- [Server](https://mrnewb.github.io/docs/mrnewbloottables/exports/server-exports)
- [Client](https://mrnewb.github.io/docs/mrnewbloottables/exports/client-exports)

Loot: `chance` is `lib.selector` weight. `shared = true` removes that entry from the **server-global** table after a hit. Shipped loot: `convenience_store`, `house_robbery`, `vehicle_search`, `dumpster`. Count capped at 1000. Multiple rolls cap 25.

Payout jobs need `low_tier` / `mid_tier` / `high_tier` in config; export tiers are `low` / `mid` / `high`. Ranges roll **once** at register and stay fixed until restart.

Server: `GetLootRoll(id, 'single'|'multiple', src?, maxRewards?)`, `GetSingleLootRoll`, `GetMultipleLootRolls`, `GetLootTable`, `RegisterLootTable`, `RemoveLootTable`, `RegisterPayoutTable`, `GetJobPayout(job, tier)`. Client: `GetJobPayout` only (cached rolled values).

Live name write, no relog. Items: `namechangevoucher`, `blankmarriagecertificate`, `filledcertificate`. Optional records clerk (`Enabled` ships `false`). Names: letters only, no spaces/hyphens. Newb_Bridge, ox_lib, oxmysql. ESX/QB/Qbox write via `OpenUpdatePlayerName`.

- [Landing](https://mrnewb.github.io/docs/mrnewbnamechanger)
- [Install](https://mrnewb.github.io/docs/mrnewbnamechanger/install)
- [Item setup](https://mrnewb.github.io/docs/mrnewbnamechanger/install/inventory)
- [Item images](https://mrnewb.github.io/docs/mrnewbnamechanger/install/inventory-images)

Hook (the only resource net-style event that is public):

```lua
AddEventHandler('MrNewbNameChanger:Server:NameChanged', function(src, identifier, firstName, lastName)
end)
```

Fires after voucher, filled certificate, clerk, or `ChangePlayerName`. Local server event — `AddEventHandler`, not `RegisterNetEvent`. Override `OpenUpdatePlayerName` in `resource/open/server/update.lua`. Framework slug from `bridge.framework.getResourceName()` (`qb-core` / `qbx_core` / `es_extended`).
