<Callout type="info">
  You need Newb_Bridge, ox_lib, oxmysql, and a framework and inventory the bridge supports. Start NameChanger after all of them. The full list is on [Requirements](/mrnewbnamechanger/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbNameChanger` folder in your `resources` folder. There is no SQL file to import. QB and Qbox save names through the framework. ESX updates `users.firstname` and `users.lastname`, and a custom identity setup can override that in `resource/open/server/update.lua`.

### Add the items [step]

There are three items: `namechangevoucher`, `blankmarriagecertificate` and `filledcertificate`. Their names have to match the config. Paste them from [Item setup](/mrnewbnamechanger/install/inventory), then copy the pictures from [Item images](/mrnewbnamechanger/install/inventory-images).

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewbNameChanger
```

### Configure it [step]

Open `configs/config.lua` for the item names, the name filter, marriage rules and the records clerk. Every setting is on [Configuration](/mrnewbnamechanger/install/configuration).

### Restart and check [step]

Restart the server after config or item changes. Item use is registered at start, so do not register the voucher a second time anywhere else.
