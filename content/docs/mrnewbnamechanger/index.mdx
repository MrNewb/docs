Name vouchers, marriage certificates, and a records clerk if you want one. The name changes right then. Nobody has to relog. Runs on [Newb_Bridge](/newb_bridge/getting-started).

[GitHub](https://github.com/MrNewb/MrNewbNameChanger) · [Configuration](/mrnewbnamechanger/install/configuration) · [Exports](/mrnewbnamechanger/exports)

## Features

- `namechangevoucher`: personal name change
- Blank marriage certificate: officiant fills it, recipient uses the signed copy
- Optional job gate for officiants (`Config.Marriage`)
- Optional paid records clerk (`Config.RecordsClerk`)
- Name filter: letters only, max length, blocked words
- Certificate NUI for both filing and viewing

Config and the open name-write hook: [Configuration](/mrnewbnamechanger/install/configuration). Item names: [Item setup](/mrnewbnamechanger/install/inventory). Icons: [Item images](/mrnewbnamechanger/install/inventory-images). Scripted changes: [Exports](/mrnewbnamechanger/exports).
