<Callout type="warning">
  Kora Framework is in alpha, so its API can change. Start order matters: the Kora resources first, then Newb_Bridge, then this script.
</Callout>

This is the install for Pawn on **kora_core**, **kora_inventory** and **kora_target**. The standard steps are on [Installation](/mrnewbpawn/install); this page replaces the framework-specific parts.

### Set up the Kora stack [step]

Install `kora_sql`, `kora_lib`, `kora_core`, `kora_inventory` and `kora_target` as described in the [kora_core docs](https://github.com/KoraFiveM/kora_core/blob/dev/docs.md), then [Newb_Bridge](/newb_bridge). Newb_Bridge finds the Kora resources by itself. See [Kora Framework](/newb_bridge/kora) for how it picks them and how to pin them.

### Add the items [step]

Kora does not read `ox_inventory/data/items.lua`. Open the **Kora** tab on [Item setup](/mrnewbpawn/install/inventory) and add its records to `KoraCoreSeed.items` in `kora_core/shared/items.lua`. Each record is `{ name = '...', label = '...', weight = 0, type = 'item', image = '....png', unique = false, useable = false, shouldClose = true, description = '...' }`. Skip any item name that is already in that file. A kora_core update can overwrite the file, so keep a copy of your additions.

### Add the images [step]

Copy the PNGs named on [Item images](/mrnewbpawn/install/inventory-images) into `kora_inventory/images/`.

### Configure [step]

Configure as normal on [Configuration](/mrnewbpawn/install/configuration). Job names and grades follow the Kora notes above.

### Add to server.cfg [step]

```cfg
ensure ox_lib
ensure kora_sql
ensure kora_lib
ensure kora_core
ensure kora_inventory
ensure kora_target
ensure Newb_Bridge
ensure MrNewbPawn
```

### Restart the server [step]

Restart the server, not individual resources. Newb_Bridge in particular should not be restarted live on Kora.
