<Callout type="info">
  You need Newb_Bridge, ox_lib, and a framework, inventory and target the bridge supports. Start Pawn after all of them. The full list is on [Requirements](/mrnewbpawn/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbPawn` folder in your `resources` folder. oxmysql is not needed.

### Add the items [step]

The 20 items Pawn trades in are not usable items. Paste their names from [Item setup](/mrnewbpawn/install/inventory) if you do not already have them, then copy the pictures from [Item images](/mrnewbpawn/install/inventory-images).

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewbPawn
```

### Configure it [step]

Open `resource/open/shared/config.lua`. Shops, buy-back, foundries and melt recipes are explained on [Configuration](/mrnewbpawn/install/configuration). Leave debug off on a live server.

### Restart and check [step]

Restart the server after config, locale or item changes. Sold stock is kept in memory per shop, so it resets on restart.
