---
title: "Anticheat models"
description: "Object models to allow so anticheats do not delete the hives, traps, and separator."
icon: "IconShield"
---

Allow these object models so they are not deleted as unauthorized props.

| Model | Used as |
| --- | --- |
| `jim_g_beehive_prop_2` | Standard hive, closed |
| `jim_g_beehive_prop_3` | Standard hive, open |
| `jim_g_beehive_smoker_prop_4` | Smoker (handheld) |
| `jim_g_beehive_prop_1` | Older handheld, still streamed |
| `mrnewb_hive_closed` | Rustic hive, closed |
| `mrnewb_hive_open` | Rustic hive, open |
| `mrnewb_hive_lid` | Hive lid, streamed |
| `mrnewb_hive_lid_off` | Hive lid off, streamed |
| `mrnewb_hive_open_empty` | Open empty hive, streamed |
| `mrnewb_bee_trap` | Bee trap |
| `mrnewb_honeycomb_frame` | Honeycomb frame |
| `mrnewb_honey_crank_static` | Crank separator, placed |
| `mrnewb_honey_crank_shell` | Crank separator shell |
| `mrnewb_honey_crank_empty` | Crank separator, empty |
| `mrnewb_honey_separator_static` | Motor separator, placed |
| `mrnewb_honey_separator_shell` | Motor separator shell |
| `mrnewb_honey_separator_empty` | Motor separator, empty |
| `mrnewb_honey_separator_rotor` | Separator rotor, with frames |
| `mrnewb_honey_separator_rotor_empty` | Separator rotor, empty |

Drawables live under `stream/`, with `stream/mrnewb_beekeeping.ytyp`. Do not move or rename them.
