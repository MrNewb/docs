| `jim_g_beehive_prop_1` | Older handheld, still streamed |
| `mrnewb_hive_closed` | Rustic hive, closed |
| `mrnewb_hive_open` | Rustic hive, open |
| `mrnewb_hive_lid` | Hive lid |
| `mrnewb_jim_hive_body` | Animated standard hive body |
| `mrnewb_jim_hive_lid` | Animated standard hive lid |
| `mrnewb_bee_trap` | Bee trap |
| `mrnewb_honeycomb_frame` | Honeycomb frame |
| `mrnewb_honey_mason_jar` | Jar shown while separating |
| `mrnewb_honey_crank_static` | Crank separator, placed |
| `mrnewb_honey_crank_shell` | Crank separator shell |
| `mrnewb_honey_crank_empty` | Crank separator, empty |
| `mrnewb_honey_crank_handle` | Crank handle |
| `mrnewb_honey_crank_rotor` | Crank rotor, with frames |
| `mrnewb_honey_crank_rotor_empty` | Crank rotor, empty |

Drawables live under `stream/`, with `stream/mrnewb_beekeeping.ytyp`. Do not move or rename them.
