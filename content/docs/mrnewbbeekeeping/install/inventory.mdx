Paste the matching snippet into your items file, then copy PNGs from `[INSTALL]/imgs/` (see [Item images](/mrnewbbeekeeping/install/inventory-images)).

| Inventory | Image folder |
| --- | --- |
| ox_inventory | `ox_inventory/web/images/` |
| qb-inventory / ps-inventory | `html/images/` |
| one_inventory | `one_inventory/web/images/` |

- **OX** — `ox_inventory/data/items.lua` (ESX and Qbox that run ox use this tab). Same text ships as `[INSTALL]/ox_inventory_items.txt`.
- **QB** — `qb-core/shared/items.lua` (or your shared items path).
- **one_inventory** — add the item defs in that resource’s format; you still need the PNGs in its images folder.

Restart the inventory resource after pasting. Item names have to match the setup panel. If you rename one there, register that name instead.

<Callout type="info">
  Usable items are `beehive`, `beehive_rustic`, `honey_separator`, `queen_bee`, `bee_trap`, `beekeeping_guide`, and `beekeeper_suit`.
</Callout>
