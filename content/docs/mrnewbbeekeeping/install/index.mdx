<Callout type="info">
  You need Newb_Bridge 0.1.3 or newer, ox_lib 3.40.2 or newer, oxmysql and an inventory the bridge supports. Start BeeKeeping after all of them. The full list is on [Requirements](/mrnewbbeekeeping/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbBeeKeeping` folder in your `resources` folder. There is no SQL file, because the tables are created the first time it starts.

### Add the items [step]

There are 17 items. Paste the list for your inventory from [Item setup](/mrnewbbeekeeping/install/inventory), then copy the pictures from [Item images](/mrnewbbeekeeping/install/inventory-images).

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewbBeeKeeping
```

### Restart and open the setup [step]

Restart the server, join as staff and type `/setupbeekeeping`. The panel walks you through the rest, and [Configuration](/mrnewbbeekeeping/install/configuration) explains each page.

If you are updating from an older version, your hives are converted on the first start. Restart once more if the console says it converted them.

To check it worked, give yourself a hive, place it, add a queen and workers, then close it.
