Staff change settings with `/hivesetup`. A save applies immediately. No restart.

The first time the panel opens, a short guide walks Access, Swarms, Shops, Honey, Bee trap, Suit, Genetics, Saving, VIP, and Logs. You can leave it and use the full page list whenever you want.

## Pages

| Page | What it controls |
| --- | --- |
| Hives | Owner-only or allowlist access, hive types and models, max hives per player (`0` = unlimited), own-hive blips, honey minigame (`slide`, `none`, `ox`, or a supported third-party), debug |
| Placement | Max place distance, place time, minimum distance between hives, allowed ground materials |
| Wild swarms | `stationary`, `randomized`, or `off`. Locations, stings, respawn, catch limits, who can see them |
| Shops | Keeper stands (ped, prop, or box), stock and prices, honey and wax sell prices, `PayTo` (`bank` or `cash`), context menu fallback |
| Honey zones | Map polygons per region, and priority when regions overlap. Outside every region the hive makes default honey |
| Separator | On or off, `static` spots or an `item` players place, crank or motor, combs per batch, mouse mode and spin turns |
| Production | Minutes per tick, max honey / wax / workers, worker loss chance |
| Saving and cleanup | `shutdown` or `timed` saving, inactive hive wipe days |
| VIP hives | Extra slots. VIP from an identifier list, ACE groups, Discord roles, or the hook |
| Logs | `ox` (ox_lib logger), `discord` (webhook), or `custom` (`SendBeeLog`). Per-action toggles |

`shutdown` writes hives when the resource stops or the server restarts. A crash loses changes since boot. Use `timed` if that matters.

Zone and location editing uses the built-in map in the panel. Place the points, then save.

## Player flow

1. Use a hive item. Ground has to be allowed, and the spot has to sit outside blocked zones, far enough from the next hive, and under the personal cap.
2. Add workers and a queen. Production ticks only while the hive is **closed**, the queen is alive, workers are above zero, and honey / wax are not already full.
3. Open the hive to extract. The slide minigame clears cells until 2 percent or fewer remain, or times out at 120 seconds. Fail or timeout stings unless `OnMinigameFailed` returns true.
4. Honey type follows the region the hive sits in. With the separator on, the hive gives `honeycomb`. Load frames and spin them for jars.
5. Wild swarms sting unless the suit is on. Place a `bee_trap` in the sting zone, wait, then collect. A queen is about a 10 percent catch by default.
6. Sell honey and wax at the shop. Shop location ids have to match a stock list entry.

## Strains

Queens carry a strain that changes honey, wax, lifespan, and how they do in each region. Shipped strains include Balanced Stock, Prolific Forager, Wax Weaver, the regional blooms, Hardy Stock, Docile Matriarch, Urban Scout, Iron Comb, Storm Chaser, Wild Feral, plus Amber Legacy and Golden Royal (those two are staff grants). Players read them with `beekeeping_guide`. New strains from the builder are stored in the database.

## Open files

These stay editable. They hold code, not the panel data. A change here needs a resource restart.

| Function | File | Role |
| --- | --- | --- |
| `Config.IsHiveAdmin(src)` | `open/server/custom.lua` | Who can open `/hivesetup` |
| `Config.IsPlayerHiveVip(src)` | `open/server/custom.lua` | Return true to grant VIP slots |
| `SendBeeLog(src, action, message)` | `open/server/custom.lua` | Used when the log provider is `custom` |
| `RollQueenTrait(src, zone)` | `open/server/custom.lua` | Return a trait id, or `''` for the default roll |
| `ResolveHoneyRewardItem(...)` | `open/server/custom.lua` | Return another item name, or `false` to give nothing |
| `OnTrapCatch(src, swarmId, context)` | `open/server/custom.lua` | After a successful swarm catch |
| `OnMinigameFailed()` | `open/client/custom.lua` | Return true to skip the sting |
| `OnAttachHoneycomb()` / `OnAttachHiveSmoker()` | `open/client/custom.lua` | Return true to skip the built-in prop |
| `ApplyBeekeeperSuit` / `RestoreBeekeeperSuit` | `open/client/custom.lua` | Your own clothing. Return true when you handled it |

Honey minigame backends live in `resource/open/client/minigames.lua`.

## SQL

No file to import. On start the resource creates and migrates:

- `mrnewb_beekeeping`
- `mrnewb_beekeeping_separators`
- `mrnewb_beekeeping_separator_state`
- `mrnewb_beekeeping_traps`

Older hive rows in `mrnewb_beekeeping` are converted automatically. Restart once if the console says it converted.

Item names are set in the panel (hive types, separator, trap, suit, strain guide, honey variants). If you rename one, register that name and add a matching image.
