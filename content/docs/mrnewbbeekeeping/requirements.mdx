- [Newb_Bridge](/newb_bridge)
- ox_lib, oxmysql
- [Server artifact and OneSync](/getting-started/download#check-your-artifact)
- An [inventory Newb_Bridge supports](/newb_bridge/supported#inventory), including `one_inventory`

Optional: Badger_Discord_API, only if you match Discord roles for VIP hive slots.

Settings are edited in `/beekeepingsetup` and saved to `MrNewb__Settings`. Editable code stays in `resource/open/`.
