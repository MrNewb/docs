- [Newb_Bridge](/newb_bridge)
- ox_lib, oxmysql
- [Server artifact and OneSync](/getting-started/download#check-your-artifact)
- An inventory Newb_Bridge already supports
- Hive and separator props ship in `stream/` (`stream/mrnewb_beekeeping.ytyp` is registered in `fxmanifest.lua`)

Optional: Badger_Discord_API, only if you match Discord roles for VIP hive slots.

Keep the folder named `MrNewbBeeKeeping`. Settings are edited in `/hivesetup` and saved to `MrNewb__Settings`. Editable code stays in `resource/open/`.
