description: "What you need running before BeeKeeping starts."
icon: "IconChecklist"
---

- [Newb_Bridge](/newb_bridge) 0.1.3 or newer
- ox_lib 3.40.2 or newer, oxmysql. BeeKeeping checks both versions at start and prints a red console message if either is too old
- [Server artifact and OneSync](/getting-started/download#check-your-artifact)
- An [inventory Newb_Bridge supports](/newb_bridge/supported#inventory), including `one_inventory` and `kora_inventory`

Supported frameworks: qbx_core, qb-core, es_extended and **kora_core**. Targets: ox_target, qb-target and **kora_target**. See [Supported](/newb_bridge/supported) for the full list.

Optional: Badger_Discord_API, only if you match Discord roles for VIP hive slots.

Settings are edited in `/setupbeekeeping` and saved to `MrNewb__Settings`. Editable code stays in `resource/open/`.
