- [Newb_Bridge](/newb_bridge)
- ox_lib, oxmysql
- [Server artifact and OneSync](/getting-started/download#check-your-artifact)
- An [inventory Newb_Bridge supports](/newb_bridge/supported#inventory), including `one_inventory` and `kora_inventory`

Supported frameworks: qbx_core, qb-core, es_extended and **kora_core**. Targets: ox_target, qb-target and **kora_target**. See [Supported](/newb_bridge/supported) for the full list and [Kora install](/mrnewbbeekeeping/install/kora) if you run Kora.

Optional: Badger_Discord_API, only if you match Discord roles for VIP hive slots.

Settings are edited in `/beekeepingsetup` and saved to `MrNewb__Settings`. Editable code stays in `resource/open/`.
