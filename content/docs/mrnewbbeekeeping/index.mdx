Players place their own hives, keep queens and workers, pull honey, spin comb in a separator, sell it, and chase wild swarms. Runs on [Newb_Bridge](/newb_bridge).

## Features

- Place and own hives (standard or rustic) with a personal cap, optional VIP extras, and owner or allowlist access
- Production loop — workers make honey and wax; queen health and genetics change output. An **open** hive does not tick
- Seven regional honeys (blue, green, red, amber, lavender, citrus, wildflower) plus default wild honey
- Honey separator — with it on, hives give honeycomb frames. Spin those for jars (crank or motor)
- Queen genetics — trait strains, zone modifiers, breeding, in-game strain guide
- Wild swarms — particles, sting damage, trap catches, optional respawn
- Beekeeper suit — blocks swarm and trap stings while worn
- Beekeeper shop — buy supplies, sell honey and wax (`PayTo` is `bank` or `cash`)
- Staff panel (`/hivesetup`) — settings, hive manager, map blips, maintenance, grant queens, strain builder

## Player loop

1. Buy a `beehive` or `beehive_rustic`, workers, and a queen from the shop (or catch workers / a rare queen from a wild swarm with a `bee_trap`)
2. Use the hive item to place it on allowed ground, outside blocked zones
3. Open the colony, install the queen, add workers — production only runs while the hive is **closed**
4. Extract honey (minigame) and wax when stores fill. If the separator is on, you get `honeycomb` instead — load it and spin it for jars
5. Sell at the shop. Optional: raise a daughter queen, smoke the hive, wear the suit near swarms, read the strain guide

Staff open `/hivesetup` for settings and the hive tools. There is no config file. The first save lives in `MrNewb__Settings`.
