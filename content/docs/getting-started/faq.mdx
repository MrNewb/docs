<Accordions type="single">
  <Accordion title="How do I get a script running?">
    Start at [Download](/getting-started/download). It covers the artifact, where the files live, and the restart. After that, open the script on the left and go through Requirements, then Installation. Most of them want ox_lib and Newb_Bridge already running.
  </Accordion>

  <Accordion title="Which frameworks do you support?">
    ESX, QBCore, and Qbox. [Newb_Bridge](/newb_bridge) handles whichever one you run. If a script needs more (oxmysql, a phone), its Requirements page says so.
  </Accordion>

  <Accordion title="Why Newb Bridge instead of community_bridge?">
    Lining up goals with other folks is hard. I tried. It just wouldn't work.

    [Newb_Bridge](/newb_bridge) uses a lot less memory than community_bridge did, and it don't haul around pieces these scripts never touch. Coming off community_bridge? The rewrite is [here](/newb_bridge/developers/migrating).

    If ox_lib ships a bridge in its v2 modules, that would make everybody's life easier, and I'll move to it then. Until that happens, this is what I run.
  </Accordion>

  <Accordion title="Can I read or edit the source?">
    Free scripts on GitHub are open, so read all you want. Paid ones like BeeKeeping lock most of the Lua. `configs/`, `locales/`, and `resource/open/` stay yours to change. A few scripts have no `configs/` folder, and those keep their settings in the in-game setup panel.
  </Accordion>

  <Accordion title="Can I rename the folder?">
    No. `import.lua` and escrow both look the resource up by the name in the docs.
  </Accordion>

  <Accordion title="I'm getting a Keymaster error">
    Nine times out of ten the server was never fully restarted. See [Keymaster errors](/getting-started/download#keymaster-errors).
  </Accordion>

  <Accordion title="Still stuck">
    Ask on [Discord](https://discord.gg/mrnewbscripts). Install questions and odd errors both belong there.
  </Accordion>
</Accordions>
