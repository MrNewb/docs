### Check your artifact [step]

You want artifact `/server:6116` or newer, and OneSync on. An old build, or OneSync left off, is where a lot of "it just don't start" comes from.

<LinkEmbed href="https://runtime.fivem.net/artifacts/fivem/build_server_windows/master/" title="FiveM server artifacts" />

### Get the files [step]

Paid scripts are on Tebex. Free ones are on GitHub. If a script page shows both, either copy is the same resource.

<LinkEmbed href="https://mrnewbscripts.tebex.io/" title="Tebex store" />

<LinkEmbed href="https://github.com/MrNewb" title="GitHub" />

### Open the zip [step]

Open the zip before you touch the server. The folder that goes in `resources` is the resource itself, and the name has to stay what that script's page says (`Newb_Bridge`, `MrNewbPawn`, and so on). Don't drop an outer bundle folder in and call it done.

### Restart the server [step]

If the script is escrowed, restart the whole server. Starting it from the live console is how you get a Keymaster error. A full restart is what makes the server see the license. Open scripts can be started the normal way, but a restart still don't hurt.
