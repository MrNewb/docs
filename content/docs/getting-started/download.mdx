Every script goes in the same way: right artifact, files in `resources`, full restart. The only thing that changes is where the zip comes from.

## Check your artifact

Use artifact `/server:6116` or newer with OneSync on. A stale build or OneSync left off is behind a lot of "it just don't start."

## Drop it into resources

Unzip first and look inside. You want the resource folder itself, not the bundle it came wrapped in.

| Rule | Why |
| --- | --- |
| Keep the folder name from the script's page (`Newb_Bridge`, `MrNewbPawn`) | Escrow and `import.lua` look the resource up by that name |
| One copy only, never nested (`MrNewbPawn/MrNewbPawn`) | The server can load the wrong folder |
| Edit only configs, locales, and `resource/open/` | The rest is locked on paid scripts |

## Start the server

<Callout type="warning">
  Stop the server and start it again. Typing `ensure` in a live console is the most common reason for a Keymaster error on a paid script.
</Callout>

Open scripts can be ensured live. A full restart still never hurts.

When it's up, open the script from the sidebar and read Requirements before Installation.

## Keymaster errors

Paid scripts lock most of their Lua, and Keymaster is what approves the locked part. If one throws an error after you add it:

| Check | Fix |
| --- | --- |
| Did the whole server restart? | Stop it and start it again |
| Does the folder name match the docs? | Rename it back |
| Is there a second copy anywhere in `resources`? | Delete the extra one |

Still failing after a real restart? Ask on [Discord](https://discord.gg/mrnewbscripts).
