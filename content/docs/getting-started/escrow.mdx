Some of the paid scripts ship with most of the Lua locked. `configs/`, `locales/`, and `resource/open/` stay editable. The locked part is what Keymaster has to approve.

### Restart the whole server [step]

Dropping the folder in and running `ensure` while the server is already up is the usual Keymaster error. Stop the server and start it again so it sees the license.

### Leave the folder name alone [step]

Escrow looks up the resource by the name in the docs. Rename `MrNewbBeeKeeping` and it won't match.

### One copy [step]

Two folders with the same script, or one nested inside another (`MrNewbBeeKeeping/MrNewbBeeKeeping`), and the server grabs the wrong one. Search `resources` and keep a single folder.

### Edit the open files [step]

Config, locales, and `resource/open/` are the parts you're meant to change. Don't add `server.export` on an ox_inventory item unless that script's page says it's the exception.
