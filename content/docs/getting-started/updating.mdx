---
title: "Updating"
description: "Replace a script with a newer version cleanly, without leftover files from the old one."
icon: "IconRefresh"
---

Never paste new files over the old folder. Whatever the update removed or renamed stays behind, and that leftover is what usually breaks.

<Callout type="warning">
  If the notes mention SQL or new config keys, deal with those before you start the server.
</Callout>

## Before you touch anything

- Read what changed in the version you're installing. Updates are usually announced in the Discord. Paid assets also get a short summary on the portal.
- Copy the current resource out of `resources`. Back up the database too when the update has SQL.
- Hold on to that backup until the new version works in game.

<Callout>
  Worried you missed a changelog? You don't have to watch for them. Once an update is posted, the version checker warns you in the console on startup if your copy is out of date.
</Callout>

## Swap the folder

1. Download the new zip from where you bought or found it ([Tebex](https://mrnewbscripts.tebex.io/) or [GitHub](https://github.com/MrNewb)) and pull the resource folder out of it.
2. Stop the server.
3. Delete the old folder, then put the new one in `resources` under the same name.

Search `resources` once to be sure only one copy exists, and that it isn't nested inside a folder of the same name.

## Bring your changes over

| What you changed | What to do |
| --- | --- |
| Config values | Copy them onto the new config. Don't overwrite the new file, since updates add keys your old one lacks |
| Locale or `resource/open/` edits | Re-apply them on the new files |
| Database | Run the SQL from the notes if there is any |

## Check it

Start the server, read the console, and try the script in game. Delete the backup after that.
