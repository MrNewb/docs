| Command | Who | What it does |
| --- | --- | --- |
| `/recyclingsetup` | Admin | Opens the setup panel |
| `/staffdebug` | Anyone, but only while Debug is on | Copies the Newb_Bridge provider list and versions to your clipboard. With Debug off it says so and does nothing |

Admin means the framework admin check from Newb_Bridge, or the `group.admin` ace. Everyone else gets a no-permission notice.

Stations, types, recipes, sound, and models are pages in that panel, not extra commands. A save applies immediately.
