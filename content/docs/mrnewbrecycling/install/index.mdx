<Callout type="info">
  You need Newb_Bridge, ox_lib 3.40.2 or newer, oxmysql, and an inventory and target the bridge supports. Start Recycling after all of them. The full list is on [Requirements](/mrnewbrecycling/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewb_Recycling` folder in your `resources` folder. The settings table is created the first time it starts, so there is nothing to import.

### Check your items [step]

Recycling adds no items of its own. The seed recipes expect `phone`, `radio`, `lockpick`, `plastic`, `metalscrap` and `copper` to already exist in your inventory.

Murder mode is off by default. If you turn it on, it can hand out `phone`, `radio`, `goldchain`, `rolex` and `diamond_ring`, and it ships six items of its own in `[INSTALL]`.

<Callout type="info">
  **On Kora Framework:** Only murder mode ships its own items. If you keep it on, add these records to `KoraCoreSeed.items` in `kora_core/shared/items.lua` and copy the PNGs from `[INSTALL]/images/` into `kora_inventory/images/`. They also ship as `[INSTALL]/items/kora_items.txt`.
</Callout>

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewb_Recycling
```

### Restart and open the setup [step]

Restart the server, join as an admin and type `/setuprecycling`. [Configuration](/mrnewbrecycling/install/configuration) explains each page.

To check it worked, stand inside a machine's load radius (120 m by default), open it, load an item that has a recipe, turn it on, wait, and collect the output.
