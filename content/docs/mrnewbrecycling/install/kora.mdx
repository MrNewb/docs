<Callout type="warning">
  Kora Framework is in alpha, so its API can change. Start order matters: the Kora resources first, then Newb_Bridge, then this script.
</Callout>

This is the install for Recycling on **kora_core**, **kora_inventory** and **kora_target**. The standard steps are on [Installation](/mrnewbrecycling/install); this page replaces the framework-specific parts.

### Set up the Kora stack [step]

Install `kora_sql`, `kora_lib`, `kora_core`, `kora_inventory` and `kora_target` as described in the [kora_core docs](https://github.com/KoraFiveM/kora_core/blob/dev/docs.md), then [Newb_Bridge](/newb_bridge). Newb_Bridge finds the Kora resources by itself. See [Kora Framework](/newb_bridge/kora) for how it picks them and how to pin them.

### Items [step]

Recycling ships no items. The seed recipes expect `phone`, `radio`, `lockpick`, `plastic`, `metalscrap` and `copper` to exist in Kora's item registry. Anything missing can be added to `KoraCoreSeed.items` in `kora_core/shared/items.lua`.

### Configure [step]

Configure as normal on [Configuration](/mrnewbrecycling/install/configuration). Job names and grades follow the Kora notes above.

### Add to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure kora_sql
ensure kora_lib
ensure kora_core
ensure kora_inventory
ensure kora_target
ensure Newb_Bridge
ensure MrNewb_Recycling
```

### Restart the server [step]

Restart the server, not individual resources. Newb_Bridge in particular should not be restarted live on Kora.
