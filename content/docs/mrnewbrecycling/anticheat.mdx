Allow these object models so they are not deleted as unauthorized props.

| Model | Used as |
| --- | --- |
| `mrnewb_recycler` | Recycler body |
| `mrnewb_recycler_post` | Recycler post |
| `mrnewb_recycler_rotor_a` | Rotor, spins while that post runs |
| `mrnewb_recycler_rotor_b` | Rotor, spins while that post runs |

Drawables live under `stream/`, with `stream/mrnewb_recycler.ytyp`. The running sound is `stream/audiodirectory/recycler_sounds.awc` and `stream/data/recycler_sounds.dat54.rel`. Do not move or rename them.
