- [Newb_Bridge](/newb_bridge)
- ox_lib
- Framework, plus an [inventory Newb_Bridge supports](/newb_bridge/supported#inventory)
- A [target Newb_Bridge supports](/newb_bridge/supported#target)
- A framework that keeps a `stress` value in the player's metadata, if you want the stress relief
- [Server artifact and OneSync](/getting-started/download#check-your-artifact)

oxmysql is not required. The supply ped uses your inventory's own shop, so the inventory must be one the bridge can open shops for.
