<Callout type="info">
  You need Newb_Bridge, ox_lib, and a framework, inventory and target the bridge supports. Start Yoga after all of them. The full list is on [Requirements](/mrnewbyoga/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewb_Yoga` folder in your `resources` folder. oxmysql is not needed.

### Add the items [step]

Register the three mat items from [Item setup](/mrnewbyoga/install/inventory) and copy the pictures from `[INSTALL]/imgs/` into your inventory images folder. Yoga registers the use of each item for you, so the items need no `server.export`.

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewb_Yoga
```

### Configure it [step]

Open `resource/open/shared/config.lua`. The shipped config has one mat spot and the supply ped turned off. Every setting is on [Configuration](/mrnewbyoga/install/configuration).

### Restart and check [step]

Restart the server after config or item changes.
