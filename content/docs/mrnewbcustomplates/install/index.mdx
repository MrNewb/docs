<Callout type="info">
  You need Newb_Bridge, ox_lib, oxmysql, and a framework and inventory the bridge supports. Start CustomPlates after all of them. The full list is on [Requirements](/mrnewbcustomplates/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbCustomPlates` folder in your `resources` folder.

### Add the items [step]

There is one item, `customizableplate`. Paste it from [Item setup](/mrnewbcustomplates/install/inventory), then copy its picture from [Item images](/mrnewbcustomplates/install/inventory-images). The name has to match the one in the config.

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewbCustomPlates
```

### Configure it [step]

Open `resource/open/shared/config.lua` for the plate length, the word filter and the apply animation. Every setting is on [Configuration](/mrnewbcustomplates/install/configuration).

### Restart and check [step]

Restart the server after config or item changes.
