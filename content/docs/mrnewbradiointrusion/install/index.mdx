<Callout type="info">
  You need Newb_Bridge, ox_lib, a framework and inventory the bridge supports, and pma-voice or saltychat. Start RadioIntrusion after all of them, voice resource included. The full list is on [Requirements](/mrnewbradiointrusion/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbRadioIntrusion` folder in your `resources` folder. oxmysql is not needed.

### Add the items [step]

Register the device from [Item setup](/mrnewbradiointrusion/install/inventory). The radio a player has to carry is your server's normal `radio` item.

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure pma-voice           # or saltychat
ensure Newb_Bridge
ensure MrNewbRadioIntrusion
```

### Configure it [step]

Open `resource/open/shared/config.lua`. Every setting is on [Configuration](/mrnewbradiointrusion/install/configuration).

### Restart and check [step]

Restart the server after config or item changes.
