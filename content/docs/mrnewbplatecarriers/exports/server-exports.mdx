Both take a player source. Check the return before continuing inventory or loadout logic.

## Vest

```lua
local wearing = exports.MrNewbPlateCarriers:IsPlayerWearingVest(src)
local removed = exports.MrNewbPlateCarriers:ForceRemovePlayerVest(src)
```

`IsPlayerWearingVest` is true when the player has a carrier on. `ForceRemovePlayerVest` takes the carrier off the same way the remove command does and puts the item back in the inventory, with its condition saved.
