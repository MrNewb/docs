---
title: "Requirements"
description: "What you need running before this script starts."
icon: "IconChecklist"
---

- [Newb_Bridge](/newb_bridge)
- ox_lib
- An [inventory Newb_Bridge supports](/newb_bridge/supported#inventory) with per-item metadata (`setMetadata`), including `one_inventory`
- ESX, QBCore, or Qbox via the bridge

`Config.Settings.RequireMetadataInventory` errors on start if the bridge inventory is `esx-framework`, or `auto` with none of the known metadata inventories running.
