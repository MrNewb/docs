---
title: "Commands"
description: "Commands and keys for PlateCarriers. No admin or console commands. Every key can be rebound by the player in the FiveM key settings."
icon: "IconTerminal2"
---

| Command | Default key | What it does |
| --- | --- | --- |
| `/carriers` | `F6` | Opens the management menu: the worn carrier and the carriers in the bag |
| `/removevest` | `O` | Takes the carrier off and puts the item back in the inventory |
| `/togglevesthud` | `U` | Shows or hides the plate HUD. The choice is remembered |
| `/checkcarrier` | none | Police serial check. Lists the carriers in your bag, or the vest worn by the nearest person |

You can change the serial check command and the default keys in the config. Players can rebind the keys in the FiveM key settings.
