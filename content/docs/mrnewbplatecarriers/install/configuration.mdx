## Where you edit

`resource/open/shared/config.lua` is one file. Labels and messages are in `locales/*.json`. Restart after config or item changes.

| Key | Purpose |
| --- | --- |
| `Config.Settings` | Broken plate sound, clothing, ox_inventory drag-insert and the weight slowdown |
| `Config.Hud` | Whether the plate HUD starts visible and its key |
| `Config.Serial` | The police serial check |
| `Config.VestItems` | The carrier items, one per tier |
| `Config.RepairPlates` | The repair plate items and how much each restores |
| `Config.RegisteredKeyMapping` | Default key for removing the vest (`O`) |
| `Config.MenuKeyMapping` | Default key for the management menu (`F6`) |

### Settings

| Key | Default | Purpose |
| --- | --- | --- |
| `Config.Settings.PlayBrokenPlateSound` | `true` | Plays a break sound when the carrier's armor reaches 0 |
| `Config.Settings.DisableVestClothing` | `false` | Leave the player's clothing alone and only track armor |
| `Config.Settings.EnableOxExclusiveFeatures` | `false` | ox_inventory only: drag a repair plate onto a carrier in the inventory to repair it |
| `Config.Settings.EnableWeightSlowdown` | `true` | Heavier tiers slow the player, using each carrier's `MoveSpeed` |

### HUD

| Key | Default | Purpose |
| --- | --- | --- |
| `Config.Hud.DefaultVisible` | `true` | Whether the plate HUD shows for a player who has never toggled it |
| `Config.Hud.KeyMapping` | `U` | Default key to show or hide the HUD |

The HUD sits in the bottom right and only shows while a carrier is worn. It hides with the pause menu.

### Serial check

```lua
Config.Serial = {
    Enabled = true,
    Command = 'checkcarrier',
    Jobs = { police = 0, sheriff = 0 },
    MaxOwners = 5,
}
```

| Key | Purpose |
| --- | --- |
| `Enabled` | Turn the serial check on or off |
| `Command` | Command name players type |
| `Jobs` | Jobs that may use it, each with the lowest grade allowed |
| `MaxOwners` | How many previous owners each carrier remembers |

Every carrier gets a serial number and keeps a short owner history. The check lists carriers in the player's own bag, or the vest worn by the nearest person within 5 meters.

### Carriers

```lua
Config.VestItems = {
    ['pegasus_carrier'] = {
        Strength = 5,
        Condition = 50,
        MoveSpeed = 1.0,
        Clothing = {
            drawable = { male = 11, female = 1 },
            texture = { male = 0, female = 0 },
        },
    },
}
```

| Field | Purpose |
| --- | --- |
| `Strength` | The carrier's armor cap is `Strength * 10` |
| `Condition` | Armor a new carrier of this tier starts with |
| `MoveSpeed` | Movement speed multiplier while worn (`1.0` is normal). Used when the weight slowdown is on |
| `Clothing` | `{ drawable = { male, female }, texture = { male, female } }` |

Shipped tiers:

| Item | Strength | Max armor | Start | Speed |
| --- | --- | --- | --- | --- |
| `pegasus_carrier` | `5` | `50` | `50` | `1.0` |
| `merryweather_carrier` | `6` | `60` | `60` | `0.99` |
| `fib_carrier` | `7` | `70` | `70` | `0.97` |
| `noose_carrier` | `8` | `80` | `80` | `0.95` |
| `armstrong_carrier` | `10` | `100` | `100` | `0.92` |

### Repair plates

```lua
Config.RepairPlates = {
    ['pegasus_light_repair_plate'] = { RepairValue = 10 },
    ['merryweather_standard_repair_plate'] = { RepairValue = 20 },
    ['fib_tactical_repair_plate'] = { RepairValue = 30 },
    ['noose_heavy_repair_plate'] = { RepairValue = 40 },
    ['armstrong_elite_repair_plate'] = { RepairValue = 50 },
}
```

`RepairValue` is how much armor the plate adds to a carrier. A plate that would take the carrier over its maximum is refused and not used. Keep these item names on upgrade.

## Clothing

The clothing table is **drawable and texture per gender**, not the component index. The component is fixed: the carrier uses `SetPedComponentVariation` on component **9** (body armor). Shipped drawables are `male = 11` and `female = 1` for every carrier, with texture `0`. Change the drawable numbers to match your clothing pack.

Freemode peds only (`mp_m_freemode_01` and `mp_f_freemode_01`). `DisableVestClothing` skips the clothing change.

## Metadata

Each carrier item stores its condition, strength, serial number and owner history in item metadata, so you need an inventory that can store metadata on an item. A carrier worn when a player leaves is saved with the player and restored on login, including its armor and clothing.

Repair plates: `pegasus_light_repair_plate`, `merryweather_standard_repair_plate`, `fib_tactical_repair_plate`, `noose_heavy_repair_plate` and `armstrong_elite_repair_plate`.
