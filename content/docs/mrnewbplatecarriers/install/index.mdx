<Callout type="warning">
  Start this **after** ox_lib, your framework, your inventory, and Newb_Bridge. The bridge looks at what’s already running. If this script starts first, it can miss them.
</Callout>

### Dependencies [step]

[Newb_Bridge](/newb_bridge), ox_lib, and an inventory that stores per-item metadata (`setMetadata`).

### Add items and images [step]

Paste defs from [Item setup](/mrnewbplatecarriers/install/inventory). Copy PNGs from `[INSTALL]/item_images/` into:

| Inventory | Image folder |
| --- | --- |
| ox_inventory | `ox_inventory/web/images/` |
| qb-inventory / ps-inventory | `html/images/` |
| one_inventory | `one_inventory/web/images/` |
| Kora (kora_inventory) | `kora_inventory/images/` |

Keep the existing repair-plate names during an upgrade.

### Configure [step]

Edit `resource/open/shared/config.lua` for the carrier tiers, repair plate values, clothing drawables, the HUD, keys and the serial check.

Optional Buckshot_Crafting recipes: `[INSTALL]/crafting/README.md`.

<Callout type="info">
  **Running Kora Framework?** Follow the dedicated [Kora install](/mrnewbplatecarriers/install/kora) instead of the framework steps on this page.
</Callout>

### Add to server.cfg [step]

Swap `qbx_core` / `ox_inventory` for whatever you actually run.

```cfg
ensure ox_lib
ensure qbx_core
ensure ox_inventory
ensure Newb_Bridge
ensure MrNewbPlateCarriers
```

### Restart the server [step]

Restart after config or item changes. Commands: [Commands](/mrnewbplatecarriers/install/commands).
