Gift boxes you set up. Some stuff always comes out, some of it is a weighted roll, and you can throw money in there too. Runs on [Newb_Bridge](/newb_bridge/getting-started).

[Tebex](https://mrnewbscripts.tebex.io/package/6878322) · [GitHub](https://github.com/MrNewb/MrNewbGiftBox) · [Configuration](/mrnewbgiftbox/install/configuration) · [Exports](/mrnewbgiftbox/exports/server-exports)

## Features

- One usable item per key in `Config.GiftBoxes`
- Per-entry `always` (always granted) or `weight` (relative chance via `lib.selector`)
- Optional `account` reward (`cash` / `bank` / `money`)
- Cancellable unwrap progress on the client
- Guaranteed rewards are space-checked before the box is consumed
- Server exports to give a box or grant that box's rewards without unwrapping

Box keys and reward fields: [Configuration](/mrnewbgiftbox/install/configuration). Item paste: [Item setup](/mrnewbgiftbox/install/inventory). Icon: [Item images](/mrnewbgiftbox/install/inventory-images). Giving a box from another script: [Exports](/mrnewbgiftbox/exports/server-exports).

No commands.
