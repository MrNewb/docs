City hall desks. A new ID, a job on the spot, or an application. Discord webhooks if you want them. Runs on [Newb_Bridge](/newb_bridge/getting-started).

[GitHub](https://github.com/MrNewb/MrNewbCityHall) · [Discord](https://discord.gg/mrnewbscripts) · [Configuration](/mrnewbcityhall/configuration)

## Features

- Walk-up job assignment per desk (`availableJobs` → grade)
- Bank-paid ID replacement via `um-idcard`, `bl_idcard`, or an `id_card` inventory item
- Job applications with optional Discord webhooks
- Multiple desks, optional map blips, target via the bridge

Jobs, applications, and webhooks: [Configuration](/mrnewbcityhall/configuration).
