<Callout type="info">
  You need Newb_Bridge, ox_lib, a framework (jobs, bank money, name and date of birth) and a target the bridge supports. Start CityHall after all of them. The full list is on [Requirements](/mrnewbcityhall/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbCityHall` folder in your `resources` folder. oxmysql is not needed.

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewbCityHall
```

CityHall hands out the ID card through `um-idcard` if it is running, otherwise `bl_idcard`, otherwise it adds your `id_card` item itself. If you use one of the first two, start it before CityHall. If you use neither, make sure `id_card` exists in your inventory. CityHall ships no items of its own.

### Configure it [step]

Open `resource/open/shared/cityhall.lua` for jobs, the ID card price and the desk, `applications.lua` for the application questions, and `webhooks.lua` for the Discord links. Each file is explained on [Configuration](/mrnewbcityhall/configuration).

### Restart and check [step]

Restart the server after config or locale changes. Applications arrive on the Discord webhook you set.
