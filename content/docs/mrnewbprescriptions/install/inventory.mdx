Everything ships ready for ox_inventory. Open `[INSTALL]/ox_inventory/items.txt`, paste the whole thing into `ox_inventory/data/items.lua`, copy the PNGs, then restart the inventory and this resource.

| Inventory | Image folder |
| --- | --- |
| ox_inventory | `ox_inventory/web/images/` |
| qb-inventory / ps-inventory | `html/images/` |
| one_inventory | `one_inventory/web/images/` |
| Kora (kora_inventory) | `kora_inventory/images/` |

<Callout type="warning">
  **Required:** set `Config.Inventory = "one_inventory"` in `Newb_Bridge/settings/bridge_resources.lua`. one_inventory provides itself as `ox_inventory` and is not fully compatible with its image paths, so on `"auto"` item images do not load. See [Newb_Bridge configuration](/newb_bridge/configuration).
</Callout>

<Callout type="warning">
  Pictures in the bottling bench and pharmacy tablet are found by item name (`<item>.png`), so keep the file names as they are.
</Callout>

On start the console prints a line for every config item your inventory is missing.

## What you need

| Item | Needed? | What it is |
| --- | --- | --- |
| `prescriptionpad` | **Yes** | Doctors write scripts with it |
| `medicalprescription` | **Yes** | The signed paper patients carry to the pharmacy |
| `medicalrecord` | **Yes** | A printed dispense record |
| `emptybottle`, `pillbinder`, `humaneextract`, `redwoodleaf`, `gingeroot`, `chiliadchili`, `sprunksyrup`, `meteoritepowder` | **Yes** for the stock catalog | Recipe ingredients, and what supply runs deliver |
| `pillboxpatch`, `redwoodrelief`, `stretchyum`, `chiliadburn`, `mollis`, `zombix`, `willies`, `spacecadet`, `mazenap`, `humaneorbit`, `upnatom`, `vinewoodglow`, `altruistcrystal`, `breezeeasy`, `clotstop`, `pillboxmend`, `delperrocalm`, `beachboost`, `eagledrops`, `cluckchews`, `coldcrusher`, `steadyheart`, `altaamoxi`, `adrenajet`, `weazelwake` | **Yes** for the stock catalog | One item per medication |
| `insurancecard` | Optional | Handed out when someone buys a plan |
| `blankpaper` | Optional | Used at the forgery desk for blank fakes |
| `boxofaspirin`, `boxofpseudoephedrine`, `bandage` | Optional | Shoplifting loot. Skip `bandage` if your framework already has one |

The names the script looks up (pad, paper, record, blank paper) are set on the Item names page of the setup panel, so you can rename them there.

## The core three

These are the items that matter most. The full file has all the rest.

<Tabs items={['OX', 'QB', 'Kora']} storageKey="inventory-items">
<Tab>

```lua
['prescriptionpad'] = {
    label = 'Prescription pad',
    weight = 100,
    stack = false,
    close = true,
    description = 'Doctor prescription pad. Use to write a new prescription.',
    client = { image = 'prescriptionpad.png' },
},

['medicalprescription'] = {
    label = 'Medical prescription',
    weight = 50,
    stack = false,
    close = true,
    description = 'Signed prescription paper. Pharmacists redeem at the mixing station.',
    client = { image = 'medicalprescription.png' },
},

['medicalrecord'] = {
    label = 'Medical record',
    weight = 50,
    stack = false,
    close = true,
    description = 'Printed pharmacy medical record. Use to view dispense details.',
    client = { image = 'medicalrecord.png' },
},
```

</Tab>
<Tab>

Repeat this shape for every item in `[INSTALL]/ox_inventory/items.txt`, using the same names, labels, and weights.

```lua
['prescriptionpad'] = { name = 'prescriptionpad', label = 'Prescription pad', weight = 100, type = 'item', image = 'prescriptionpad.png', unique = true, useable = true, shouldClose = true, description = 'Doctor prescription pad. Use to write a new prescription.' },
```

</Tab>

Kora keeps items in its shared registry, seeded from `kora_core/shared/items.lua`. Add these records to the `KoraCoreSeed.items` table in that file, then copy the PNGs into `kora_inventory/images/`. Skip any item name that is already in it.

```lua
    { name = 'medicalrecord', label = 'Medical record', weight = 50, type = 'item', image = 'medicalrecord.png', unique = true, useable = true, shouldClose = true, description = 'Printed pharmacy medical record. Use to view dispense details.' },
    { name = 'medicalprescription', label = 'Medical prescription', weight = 50, type = 'item', image = 'medicalprescription.png', unique = true, useable = true, shouldClose = true, description = 'Signed prescription paper. Pharmacists redeem at the mixing station.' },
    { name = 'prescriptionpad', label = 'Prescription pad', weight = 100, type = 'item', image = 'prescriptionpad.png', unique = true, useable = true, shouldClose = true, description = 'Doctor prescription pad. Use to write a new prescription.' },
```

This tab shows the core three. The full list is `[INSTALL]/items/kora_items.txt`.

## Adding your own medication

1. Create the item in your inventory with an image named `<item>.png`
2. Add an entry with the **same name** on the meds page, or call `RegisterPrescription` from another resource
3. Restart the inventory and this resource

Full walkthrough with effects: [Medications and effects](/mrnewbprescriptions/effects).
