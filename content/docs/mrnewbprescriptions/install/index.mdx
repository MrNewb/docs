<Callout type="info">
  You need Newb_Bridge, ox_lib 3.40.2 or newer, oxmysql, and a framework and inventory the bridge supports. Start Prescriptions after all of them, and after your ambulance job if you use one. The full list is on [Requirements](/mrnewbprescriptions/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbPrescriptions` folder in your `resources` folder. The tables are created for you the first time it starts, so there is no SQL file to import.

### Add the pharmacy job [step]

Player-run pharmacies need a job in your framework. Add it from [Pharmacy job](/mrnewbprescriptions/install/pharmacy-job). It takes a couple of minutes.

### Add the items [step]

Paste the list for your inventory from [Item setup](/mrnewbprescriptions/install/inventory), then copy the pictures from [Item images](/mrnewbprescriptions/install/inventory-images).

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure qbx_medical       # your ambulance job, optional
ensure MrNewbPrescriptions
```

### Restart and open the setup [step]

Restart the server and watch the console. Every item missing from your inventory gets a line, so fix those before you go live. Then join as an admin and type `/setupprescriptions`. A short guide plays the first time. Point each pharmacy at your job, place the stations and check the medication list. [Configuration](/mrnewbprescriptions/install/configuration) explains each page.

If you are updating from a version that had addiction, the old `prescription_addiction` table is dropped on this first start.

### Check it works [step]

Before you open up, make sure:

- [ ] The console shows no red errors and no missing item lines
- [ ] `/setupprescriptions` opens for an admin
- [ ] A doctor can write a script and the paper opens when used
- [ ] Staff can clock in, bottle a script and ring up a customer, and the customer can accept
- [ ] Debug mode and every test command are off
