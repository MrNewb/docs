<Callout type="warning">
  Kora Framework is in alpha, so its API can change. Start order matters: the Kora resources first, then Newb_Bridge, then this script.
</Callout>

This is the install for Prescriptions on **kora_core**, **kora_inventory** and **kora_target**. The standard steps are on [Installation](/mrnewbprescriptions/install); this page replaces the framework-specific parts.

### Set up the Kora stack [step]

Install `kora_sql`, `kora_lib`, `kora_core`, `kora_inventory` and `kora_target` as described in the [kora_core docs](https://github.com/KoraFiveM/kora_core/blob/dev/docs.md), then [Newb_Bridge](/newb_bridge). Newb_Bridge finds the Kora resources by itself. See [Kora Framework](/newb_bridge/kora) for how it picks them and how to pin them.

### Add the items [step]

Kora does not read `ox_inventory/data/items.lua`. Open the **Kora** tab on [Item setup](/mrnewbprescriptions/install/inventory) and add its records to `KoraCoreSeed.items` in `kora_core/shared/items.lua`. Each record is `{ name = '...', label = '...', weight = 0, type = 'item', image = '....png', unique = false, useable = false, shouldClose = true, description = '...' }`. Skip any item name that is already in that file. A kora_core update can overwrite the file, so keep a copy of your additions.

### Add the images [step]

Copy the PNGs named on [Item images](/mrnewbprescriptions/install/inventory-images) into `kora_inventory/images/`.

### Pharmacy job [step]

A player-run pharmacy needs a job that exists in Kora. The record format for Kora jobs is not in the public kora_core docs, so add the job the way your Kora server already adds jobs, then use that exact name in `/prescriptionssetup` under **Shops**. The sample job and its grades are on [Pharmacy job](/mrnewbprescriptions/install/pharmacy-job). Kora grades start at 1; the script uses the zero-based grade and the bridge converts it.

### Configure [step]

Configure as normal on [Configuration](/mrnewbprescriptions/install/configuration). Job names and grades follow the Kora notes above.

### Add to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure kora_sql
ensure kora_lib
ensure kora_core
ensure kora_inventory
ensure kora_target
ensure Newb_Bridge
ensure MrNewbPrescriptions
```

### Restart the server [step]

Restart the server, not individual resources. Newb_Bridge in particular should not be restarted live on Kora.
