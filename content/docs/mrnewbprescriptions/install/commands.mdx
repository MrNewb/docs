## Doctors

| Command | What it does |
| --- | --- |
| `/prescription` | Opens the write pad. Only available when the **Prescription pad** setting lets doctors open the pad with a command instead of the item, or allows both. You can rename the command on the same setting |

Most doctors just use the `prescriptionpad` item.

## Admins

| Command | What it does |
| --- | --- |
| `/setupprescriptions` | Opens the in-game setup |
| `/staffdebug` | Copies a short Newb_Bridge provider report to your clipboard for support. Needs Debug turned on in the panel |

## Test commands

Each one is off until you turn its switch on in the panel's Extras page, and all of them should stay off on a live server.

| Command | What it does |
| --- | --- |
| `/testprescription` | Opens a sample prescription paper |
| `/testdoctorcreate` | Opens the doctor write pad |
| `/testbottling` | Opens the bottling minigame |

<Callout type="warning">
  With **Debug mode** on, the clocked-in check on billing, supply runs, and the panic button is skipped. Do not leave it on.
</Callout>
