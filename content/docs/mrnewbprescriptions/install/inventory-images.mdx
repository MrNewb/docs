Copy every PNG from `[INSTALL]/imgs/` into your inventory images folder. Keep the file names. The bottling bench and pharmacy tablet look pictures up by item name.

| Inventory | Destination |
| --- | --- |
| ox_inventory | `ox_inventory/web/images/` |
| qb-inventory / ps-inventory | `html/images/` |
| one_inventory | `one_inventory/web/images/` |

Two files are not named after a real item. `paper.png` is the icon for `blankpaper`, and `misc_prescription.png` is a generic icon the pharmacy tablet shows for prescription paper. Copy both anyway.

For your own medications, add `<itemname>.png` so the bottling bench can show it.
