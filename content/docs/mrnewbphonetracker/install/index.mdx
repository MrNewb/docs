<Callout type="info">
  You need Newb_Bridge, ox_lib, a framework and inventory the bridge supports, and one supported phone resource. Start PhoneTracker after all of them, phone included. The full list is on [Requirements](/mrnewbphonetracker/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbPhoneTracker` folder in your `resources` folder. oxmysql is not needed.

### Add the items [step]

There is one item, `tracker`. Paste it from [Item setup](/mrnewbphonetracker/install/inventory), then copy its picture from [Item images](/mrnewbphonetracker/install/inventory-images).

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure lb-phone              # or your phone
ensure MrNewbPhoneTracker
```

### Configure it [step]

Open `resource/open/shared/config.lua` for the job that can use it, the item name and the ping cooldown. Every setting is on [Configuration](/mrnewbphonetracker/install/configuration).

### Restart and check [step]

Restart the server after config or item changes. If more than one supported phone is running, PhoneTracker uses the first one it finds started, which is not always the first to start. See [Phones](/mrnewbphonetracker/compatibility/phones).
