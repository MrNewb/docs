Vehicle keys, locks, hotwiring, lockpicking, a key fob, and locksmith work. Runs on [Newb_Bridge](/newb_bridge). QBCore, Qbox, and ESX all go through the bridge.

[Discord](https://discord.gg/mrnewbscripts) · [Commands](/mrnewbvehiclekeys/install/commands) · [Exports](/mrnewbvehiclekeys/exports/server-exports)

## Features

- Item keys or virtual keys. On ox_inventory the keyring can be a real container
- Lock and unlock, engine toggle, ignition insert mode, walk-up proximity lock
- Hotwire, lockpick, search the car for keys, carjacking
- On-screen key fob (remote start, doors, self-park, summon, autopilot, and the rest of the button list)
- Walk-up locksmith ped and a player locksmith job, plus job key lockers
- GPS tracker (`ping_transmitter` / `ping_receiver`)
- Aftermarket locks so old keys stop working
- Admin setup menu (`/vehiclekeyssetup`) and an admin key panel (`/vehiclekeyadmin`)
