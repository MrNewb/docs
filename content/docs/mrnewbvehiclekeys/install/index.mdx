<Callout type="warning">
  Start this **after** ox_lib, oxmysql, your inventory, and Newb_Bridge. If ox_inventory starts later, the keyring falls back to the old style.
</Callout>

### Dependencies [step]

[Newb_Bridge](/newb_bridge), [ox_lib](https://github.com/overextended/ox_lib), [oxmysql](https://github.com/overextended/oxmysql), and [Server artifact and OneSync](/getting-started/download#check-your-artifact). You do not edit the framework for this.

Check the `provide 'qbx_vehiclekeys'` line before the first start. Details: [Requirements](/mrnewbvehiclekeys/requirements).

### Add the items and images [step]

Paste from [Item setup](/mrnewbvehiclekeys/install/inventory). The same text ships as `[INSTALL]/ox_inventory_items.txt` and `[INSTALL]/qb-core_items.txt`.

Copy every PNG from `[INSTALL]/images/` into your inventory images folder.

- ox_inventory: `ox_inventory/web/images/`
- qb-inventory: `qb-inventory/html/images/`

`hotwire_kit` is optional until you turn on “require an item to hotwire”. Leave the item in anyway. The script sets the slot count.

### Add to server.cfg [step]

Skip the ox_inventory line if you are not using it.

```cfg
ensure ox_lib
ensure oxmysql
ensure Newb_Bridge
ensure ox_inventory
ensure MrNewbVehicleKeys
```

### First start [step]

Start the server once. SQL tables are created on their own, including `MrNewb__Settings`. There is no SQL file to import.

Join as an admin and run `/setupkeys`. The first time it opens, a guided setup asks one question per page: how keys work, the fob, street cars, the engine, the keyring, throwing keys, break-in, police alerts, and the locksmith. Each page shows a recommended answer. Take it, or change it. Press **Save** when you are done.

Advanced pages and settings stay hidden until you turn on **Advanced settings** in the left rail. The Save button shows how many changes are waiting. After a save, the panel lists the few settings that need a resource restart. Everything else is live for every player.

Settings are stored in the database (`MrNewb__Settings`). The files under `resource/open/seed/` are only copied in on the first boot. After that the database copy wins and editing the seed does nothing. **Reset to the factory setup** in the panel loads the seed defaults over your saved settings.

What each page does: [Configuration](/mrnewbvehiclekeys/install/configuration).

### Restart and check [step]

Restart the inventory, then this resource, after you paste items. Give yourself a key, lock a car with **L**, and open the fob.

Commands: [Commands](/mrnewbvehiclekeys/install/commands). Locker models: [Anticheat models](/mrnewbvehiclekeys/anticheat).

## Good to know

- Restarting the resource takes a moment. The key system starts about 2 seconds after the resource does, so wait a moment before you test.
- The resource starts in about 0.25 seconds of server time. Blip icons ship as one atlas image (`web/build/blips/atlas.webp` and `atlas.json`), so the web UI build stays small. Do not delete files from `web/build`.
- Restarting this resource also stops MrNewbVehicleKeysPhone. Start it again afterwards ([Phone app](/mrnewbvehiclekeys/phone)).

## Keys players press

Players can rebind these under MrNewbVehicleKeys in FiveM’s settings.

| Key | What it does |
| --- | --- |
| L | Lock or unlock the closest car you have a key for, about 15 meters. The on-screen fob reaches further |
| Y | Toggle the engine. Stays off if your HUD already handles the engine |
| . (period) | Open the keyring UI, when the keyring UI is on. Leave it unbound for `/keyring` only. On ox_inventory without the menu you open the keyring item instead |
| E | Hotwire, driver seat only, when you do not have a key |
| H | Search the car for keys, driver seat only |
| I / O | Put the key in the ignition, or take it back out, when insert mode is on |
| F11 | Change the auto-pilot mode while it is running |
| Throw key (no key until you set one) | Throw the key for the car you sit in. Set the default key on the Keybinds page of `/setupkeys`, and players can rebind it in FiveM's key bindings. While the key fob screen is open, the screen listens for the server's default key (a letter, a digit or an F key), because the game does not hear key bindings while the screen has focus |

Walking up to your own car locks and unlocks it. Players can turn that off from the fob or with `/newb_proximitylocks`.

## Common setup mistakes

| Symptom | Check |
| --- | --- |
| Keyring is the context menu | ox_inventory started after this resource, or container keyring is off in the setup menu |
| Two `/car` commands | `AdminCommands` is on and qbx_core still registers its own `/car` and `/dv`. Turn one of them off |
| `provide` conflict on start | Another resource also provides `qbx_vehiclekeys` |
| Shop will not sell a renamed item | The locksmith price entry key has to be the real item name |
| Seed file edits do nothing | The database copy wins after the first boot. Use `/setupkeys` |
| Locker props deleted | Allow the models on [Anticheat models](/mrnewbvehiclekeys/anticheat) |
