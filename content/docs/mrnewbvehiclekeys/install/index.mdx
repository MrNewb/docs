<Callout type="info">
  You need Newb_Bridge, ox_lib 3.40.2 or newer, oxmysql and an inventory the bridge supports. Start Vehicle Keys after all of them. The full list is on [Requirements](/mrnewbvehiclekeys/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbVehicleKeys` folder in your `resources` folder. There is no SQL file to import, because the tables are created the first time it starts.

### Add the items [step]

Paste the item list for your inventory from [Item setup](/mrnewbvehiclekeys/install/inventory), then copy the pictures from [Item images](/mrnewbvehiclekeys/install/inventory-images). Kora has no file to paste, so its records are on the Item setup page.

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewbVehicleKeys
```

### Restart and run the setup [step]

Restart the server, join as an admin and type `/setupkeys`. The first time, it asks one question per page and suggests an answer for each. Take the suggestion or change it, then press **Save**.

To check it worked, give yourself a key and press **L** next to the car.
