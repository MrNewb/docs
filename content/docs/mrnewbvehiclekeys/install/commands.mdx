## Anyone

| Command | What it does |
| --- | --- |
| `/clearoldkeys` | Deletes keys for cars that are not spawned. Keys for cars that are out stay. 30 second cooldown. Only when keys are real items |
| `/anchor` | Drops or raises the anchor on a nearby boat, jetski, or sub. Within 8 meters, slower than 10 mph. Works from the shore |
| `/newb_proximitylocks` | Turns your own walk-up auto lock on or off. Same toggle as the fob |
| `/keyring` | Opens the keyring UI. Only when the keyring UI is on (`InventoryKeys.KeyringUI`) and its open setting allows the command. See [Keyring UI](/mrnewbvehiclekeys/install/configuration#keyring-ui) |
| `/givekeys` | Only when keys are virtual. Shares the closest car you have a key for with the nearest player. You need to be within 10 meters of that car. Five second cooldown |
| `/throwkeys` | Tosses a key on the ground. Not registered on ox_inventory — use the Throw Keys button on the item, or the keyring UI on virtual keys. On other inventories, sit in the car first |

## Admins

These use the admin check from the bridge.

| Command | What it does |
| --- | --- |
| `/vehiclekeyssetup` | Setup menu with a search box across every setting. Items, keybinds, hotwire, lockpicking, the locksmith, police alerts, and the rest. Its **Manage** tab gives or takes keys, shows what a player is holding, edits vehicle locks, creates keys, and places parking spots for self-park |
| `/admingivekeys [id] [plate]` | Gives that player a key. Example: `/admingivekeys 4 ABC123` |
| `/removekeys [id] [plate]` | Takes that plate’s key off that player |
| `/listkeys [id]` | Prints the plates they are holding to the server console |
| `/revokekeys [plate]` | Takes that plate’s key off every player who is online |
| `/devmode` | Drive and lock without a key. Run it again to turn it off. Client only, for testing |
| `/car [model] [plate] [keep]` | Spawns you into that model and gives you the key. Plate is optional. Pass anything other than `false` or `0` as the third argument to keep the car you are already in |
| `/dv [radius]` | Deletes the car you are in and takes your key. On foot, deletes cars around you. `/dv 10` is 10 meters. Default on foot is 5 |

`/car` and `/dv` are off by default. Turn them on under **General > Admin & debugging** (Advanced must be on to see that page). The command names are read when the resource starts, so a rename needs a restart. The on and off switches apply right away.

A command name can only belong to one resource. If another resource already owns the name, such as qbx_core's own `/car` and `/dv`, this resource skips it and prints a warning to the server console. The setup page shows the same clash. Give ours a different name on that page, or leave qbx_core's. Its `/car` already hands out keys through this script.

## Debug

Leave Debug Mode off on a live server. Turn it on under **General > Admin & debugging** (Advanced must be on). See [Debug mode](/mrnewbvehiclekeys/install/configuration#debug-mode).

The debug commands are only registered when Debug Mode was already on as the resource started. Turn it on, save, then restart the resource to get them.

| Command | What it does |
| --- | --- |
| `/whatsloaded` | Which framework, inventory, notification, and target the bridge picked, and whether item keys and ox key mode are on. The server console half prints too |
| `/debugkeys` | Reloads the client as if you just joined |
| `/debuglistkeys [id]` | Full key data for that player in the server console |
