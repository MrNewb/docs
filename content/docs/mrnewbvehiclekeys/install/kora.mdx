<Callout type="warning">
  Kora Framework is in alpha, so its API can change. Start order matters: the Kora resources first, then Newb_Bridge, then this script.
</Callout>

This is the install for Vehicle Keys on **kora_core**, **kora_inventory** and **kora_target**. The standard steps are on [Installation](/mrnewbvehiclekeys/install); this page replaces the framework-specific parts.

### Set up the Kora stack [step]

Install `kora_sql`, `kora_lib`, `kora_core`, `kora_inventory` and `kora_target` as described in the [kora_core docs](https://github.com/KoraFiveM/kora_core/blob/dev/docs.md), then [Newb_Bridge](/newb_bridge). Newb_Bridge finds the Kora resources by itself. See [Kora Framework](/newb_bridge/kora) for how it picks them and how to pin them.

### Add the items [step]

Kora does not read `ox_inventory/data/items.lua`. Set up the `newb_kora_items` importer from [Kora Framework](/newb_bridge/kora), then:

1. Open `[INSTALL]/ox_inventory_items.txt` in the script folder (the same items are listed on [Item setup](/mrnewbvehiclekeys/install/inventory)) and copy its contents.
2. Create `newb_kora_items/items/vehiclekeys.lua` containing `return {`, that block, then `}`.
3. Add `'vehiclekeys'` to the `files` list in `newb_kora_items/server.lua`.

Items that already exist in Kora are skipped, so your own edits to them stay.

### Add the images [step]

Copy the PNGs named on [Item images](/mrnewbvehiclekeys/install/inventory-images) into `kora_inventory/images/`.

### Vehicle keys provider [step]

Set `Config.VehicleKeys = "MrNewbVehicleKeys"` in `Newb_Bridge/settings/bridge_resources.lua`. If you run `kora_vehiclekeys`, remove it. This resource provides the name `kora_vehiclekeys`, so Kora resources that call it, such as garages and dealerships, use these keys. Restart those resources whenever this one restarts.

### Configure [step]

Configure as normal on [Configuration](/mrnewbvehiclekeys/install/configuration). Job names and grades follow the Kora notes above.

### Add to server.cfg [step]

```cfg
ensure ox_lib
ensure oxmysql
ensure kora_sql
ensure kora_lib
ensure kora_core
ensure kora_inventory
ensure kora_target
ensure Newb_Bridge
ensure newb_kora_items
ensure MrNewbVehicleKeys
```

### Restart the server [step]

Restart the server, not individual resources. Newb_Bridge in particular should not be restarted live on Kora.
