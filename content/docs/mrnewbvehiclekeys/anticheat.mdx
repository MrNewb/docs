The 60 makers plus five key types (`basic`, `smart`, `luxury`, `boat`, `motorcycle`). They are only spawned when the fob style is **Branded**, and a make without its own model falls back to the key type's model.

## Stock GTA models

| Model | Used as |
| --- | --- |
| `prop_cuff_keys_01` | Key fob in the hand during the fob animation (default, and the fallback for a branded key) |
| `p_car_keys_01` | A thrown key when the key has no model of its own, or when "match key prop" is off |
| `prop_cs_tablet` | The locksmith job's tablet at the bench |
| `prop_laptop_01a` | The locksmith job's computer (default model, set per place in the setup panel) |
| `u_m_y_abner` (ped) | The invisible driver for **Summon** and **Self park**. It is created, drives the car, and is removed again |
| `a_m_y_vindouche_01` (ped) | The default walk-up locksmith. The model is set per place in the setup panel |

Names come from `resource/modules/keylocker/shared/definitions.lua`, the stream folder, and the setup panel (`/setupkeys`). The streamed models load through `stream/mrnewb_keylocker.ytyp`.
