---
title: "Anticheat models"
description: "Object models to allow so anticheats do not delete the key locker or the keys."
icon: "IconShield"
---

Allow these object models so they are not deleted as unauthorized props.

| Model | Used as |
| --- | --- |
| `mrnewb_keylocker_body` | Cabinet body |
| `mrnewb_keylocker_door` | Hinged door |
| `mrnewb_keylocker_closed` | Placement preview |
| `mrnewb_keylocker_open_empty` | Open empty cabinet |
| `mrnewb_keylocker_key_classic` | Basic key |
| `mrnewb_keylocker_key_smart` | Smart key |
| `mrnewb_keylocker_key_luxury` | Luxury key |
| `mrnewb_keylocker_key_boat` | Boat key |
| `mrnewb_keylocker_key_motorcycle` | Motorcycle key |

Names come from `resource/shared/key_locker.lua`. Drawables live under `stream/`, with `stream/mrnewb_keylocker.ytyp`. Do not move or rename them.
