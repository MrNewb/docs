- [Newb_Bridge](/newb_bridge)
- ox_lib, oxmysql
- [Server artifact and OneSync](/getting-started/download#check-your-artifact)
- An inventory Newb_Bridge already supports. Start ox_inventory **before** this resource if you use it, or the keyring falls back to the old style and the console will say so

`fxmanifest.lua` provides `qbx_vehiclekeys` by default. If the real qbx_vehiclekeys (or another resource providing that name) is also started, remove that resource or delete the `provide` line. The other provide lines (`qb-vehiclekeys`, `qs-vehiclekeys`, `Renewed-Vehiclekeys`, `wasabi_carlock`, `mk_vehiclekeys`, `tgiann-hotwire`) are commented out.
