## Where you edit

One file: `resource/open/shared/config.lua`.

| Key | Purpose |
| --- | --- |
| `Config.PickingRestoreSeconds` | How long a picked plant stays gone for everyone. Shipped `2 * 60 * 60` (two hours), counted from the moment it was picked |
| `Config.PickingTypes` | What each plant type gives, the animation and the optional prop |
| `Config.PickingFields` | The areas players walk into and the plants inside them |
| `Config.BlipCategory` / `Config.BlipCategoryLabel` | Map legend group shared by the market blips |
| `Config.FarmersMarket` | Vendor NPCs. Set `Enabled = false` to skip them |

Labels: `locales/en.json`. Restart after config or item changes.

### Pick types

```lua
Config.PickingTypes = {
    apple = {
        rewardItem = { item = 'apple', count = 1, metadata = {} },
        anim = { dict = 'amb@prop_human_movie_bulb@idle_a', name = 'idle_a', flag = 1 },
    },
    pineapple = {
        rewardItem = { item = 'pineapple', count = 1, metadata = {} },
        anim = { dict = 'amb@world_human_gardener_plant@male@base', name = 'base', flag = 1 },
        propModel = 'prop_pineapple',
    },
}
```

| Field | Notes |
| --- | --- |
| `rewardItem.item` | Inventory item granted on a successful pick |
| `rewardItem.count` | Amount per pick |
| `rewardItem.metadata` | Optional. Passed to the inventory when the item is added |
| `anim` | Optional. `{ dict, name, flag }` played during the pick |
| `propModel` | Optional world model. When set, the plant is a spawned prop. When omitted, it is a sphere zone |

Shipped types: `apple`, `pineapple` and `lettuce`. Pineapple and lettuce set `propModel`; apple does not.

### Fields

A field is an area. When a player walks into it, the server sends back the plants that are available and the client spawns only those. When a plant is picked, it disappears for everyone in the field until the restore timer runs out.

```lua
Config.PickingFields = {
    grapeseed = {
        zone = {
            points = {
                vec3(2153.78, 5087.38, 44.59),
                vec3(2243.47, 4994.81, 41.05),
                vec3(2308.55, 5061.18, 44.42),
            },
            thickness = 33.00,
        },
        plants = {
            {
                plantType = 'pineapple',
                coords = {
                    vec4(2185.0920, 5062.7695, 43.6382, 154.1222),
                    vec4(2199.4265, 5061.1816, 45.5715, 36.7008),
                },
            },
        },
    },
    paleto_orchard = {
        zone = { coords = vec3(347.5, 6517.5, 30.5), radius = 25.0 },
        plants = {
            { coords = vec4(347.5, 6517.5, 30.5, 1.0), plantType = 'apple' },
        },
    },
}
```

| Field | Notes |
| --- | --- |
| `zone.points` and `zone.thickness` | A polygon field. At least three points |
| `zone.coords` and `zone.radius` | A sphere field. Use this or `zone.points` |
| `plants` | A list. Each entry has a `plantType` and either one `coords` or a list of `coords` |
| `restoreSeconds` | Optional. Overrides `Config.PickingRestoreSeconds` for this field |
| `grid` | Optional generator that fills the field with plants for you. See below |

Each `vec4` is one plant.

| Part | Meaning |
| --- | --- |
| `x`, `y`, `z` | The position |
| `w` | The heading for a prop, or the target zone radius for a sphere plant. A radius that is missing or outside `0.5` to `8.0` becomes `1.5` |

A field holds at most 256 plants. The shipped fields use at most 5 positions per plant type, so add only the plants you want. Adding plants creates more props or target zones for nearby players.

#### Grid

A `grid` fills the zone with evenly spaced plants of one type, on top of anything in `plants`.

| Field | Default | Notes |
| --- | --- | --- |
| `plantType` | the field's `plantType` | Type to place |
| `center` | the zone centre | Where the grid is centred |
| `radius` | `80.0` | Plants further than this from the centre are skipped |
| `spacing` | `8.0` | Distance between plants |
| `rotation` | `0.0` | Rotates the grid, in degrees |
| `maxPoints` | `64` | Cap on generated plants. Never above 256 |

### Props and zones

Plants with a `propModel` appear as props that spawn near players and snap to the ground. Plants without one use a sphere target zone at the configured position. Both use a target distance of `3.0`, and props spawn within 80 of the player.

There are no map blips for the fields.

### Farmers market

```lua
Config.FarmersMarket = {
    Enabled = true,
    Markets = {
        ['Mr Solitaire'] = {
            blip = { id = 52, color = 2, scale = 0.8, label = 'Farmers Market', category = Config.BlipCategory },
            entityType = 'ped',
            model = 'cs_brad',
            coords = vector4(1263.4164, 3545.6189, 35.1728, 204.9759),
            shopItems = {
                apple = 2,
                pineapple = 2,
                lettuce = 2,
            },
        },
    },
}
```

| Field | Purpose |
| --- | --- |
| `Enabled` | Skip all vendors when `false` |
| `blip` | Optional map blip: `id`, `color`, `scale`, `label` and an optional `category` |
| `model` | Ped model |
| `coords` | `vector4`, heading in `w` |
| `shopItems` | Item name to **bank** price per unit |
| `entityType` | Unused leftover. The ped comes from `model` |

Market sales pay into the player's **bank**, not an inventory money item. The menu lists every item in `shopItems`. If the player does not have the item, the sale stops and a message says why. The ped spawns within 100 of the player and the target distance is `3.0`.

## What the server checks

The server checks every pick and sale:

- You must be inside the field, within `5.0` of the plant you pick, and the plant must be available.
- Only one player can collect each plant. If the reward cannot be added, the plant becomes available again.
- Picks and sales each have a 1 second cooldown per player.
- A sale must be within `5.0` of the vendor and is capped at `1000` per request.
- Every pick and sale is logged through ox_lib's logger.

Picking takes five seconds and has no skill check.
