<Callout type="warning">
  Start this **after** ox_lib, your framework, your inventory, and Newb_Bridge. The bridge looks at what’s already running. If this script starts first, it can miss them. Keep the folder named `MrNewbOrganics`.
</Callout>

### Dependencies [step]

[Newb_Bridge](/newb_bridge), ox_lib, framework + inventory + target via the bridge. [Server artifact and OneSync](/getting-started/download#check-your-artifact). oxmysql is not required.

### Add items and images [step]

Paste the defs from [Item setup](/mrnewborganics/install/inventory). Copy PNGs from `[INSTALL]/images/` into:

| Inventory | Image folder |
| --- | --- |
| ox_inventory | `ox_inventory/web/images/` |
| qb-inventory / ps-inventory | `html/images/` |
| one_inventory | `one_inventory/web/images/` |

The pack ships `apple.png`, `pineapple.png`, and `lettuce.png`. These produce items are not usable. Market payout is **bank**, not an inventory money item.

### Configure [step]

Edit `configs/config.lua`:

- `Config.PickingTypes` — `locations` (`vector4`), `rewardItem`, `anim`, optional `propModel` (spawned prop) or omit it for a sphere zone
- `Config.FarmersMarket` — `Enabled`, vendor `model` / `coords` / `shopItems` (item → bank price)

Field tables: [Configuration](/mrnewborganics/install/configuration).

### Add to server.cfg [step]

Swap `qbx_core` / `ox_inventory` for whatever you actually run.

```cfg
ensure ox_lib
ensure qbx_core
ensure ox_inventory
ensure Newb_Bridge
ensure MrNewbOrganics
```

### Restart the server [step]

Restart after config or item changes.
