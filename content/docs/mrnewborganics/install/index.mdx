<Callout type="info">
  You need Newb_Bridge, ox_lib, and a framework, inventory and target the bridge supports. Start Organics after all of them. The full list is on [Requirements](/mrnewborganics/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbOrganics` folder in your `resources` folder. oxmysql is not needed.

### Add the items [step]

Organics ships three produce items that are not usable. Paste them from [Item setup](/mrnewborganics/install/inventory), then copy the pictures from [Item images](/mrnewborganics/install/inventory-images). Market payouts go to the bank, not an item.

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure MrNewbOrganics
```

### Configure it [step]

Open `resource/open/shared/config.lua` for the plants, the fields and the farmers market. Field tables are on [Configuration](/mrnewborganics/install/configuration).

### Restart and check [step]

Restart the server after config or item changes.
