## Config files

### Client-visible — `configs/config.lua`

| Key | Purpose |
| --- | --- |
| `Config.WeatherFeature` | `true` forces Halloween weather near shops (pauses qb-weathersync / cd_easytime / Renewed-Weathersync via `OpenSpookyToggleWeatherSync`) |
| `Config.TrickOrTreatBlips` | `true` draws trick-or-treat blips |
| `Config.Shops` | Token shops. Shipped `SpookyShop` |
| `Config.Decorations` | Prop list (`position` `vector4`, `model`) |

Shop entry:

```lua
SpookyShop = {
    position = vector4(-1726.4633, -192.4515, 58.8, 270.3187),
    model = `m24_1_prop_m41_ghost_dom_01a`,
    inventory = {
        pumpkin_basket = 25,
        rotten_casket = 50,
    },
},
```

`inventory` is item name → **event_token** cost. If `pengu_digiscanner` is started, the shop also adds `WEAPON_DIGISCANNER` (ox_inventory) or `weapon_digiscanner` (otherwise) at **15** tokens.

Override weather pause/resume in `resource/open/client/weather.lua` (`OpenSpookyToggleWeatherSync`).

### Server-only — `configs/sv_config.lua`

Do not load this on the client. Loot tables and scavenger coords stay here.

| Key | Purpose |
| --- | --- |
| `Config.LootTypes` | Named pools: `pumpkin`, `grave`, `trickOrTreat`, `pumpkin_basket`, `rotten_casket` |
| `Config.Pumpkins` | Search spots (`position`, `model`, `lootTable`) |
| `Config.Graves` | Dig spots (`position`, `lootTable`) |
| `Config.GhostHunts` | Ghost peds (`position`, `model`). Needs pengu_digiscanner |
| `Config.TrickOrTreat` | Door knocks (`targetPoint`, `model`, `pedSpawn`, `lootTable`) |

Loot row:

| Field | Purpose |
| --- | --- |
| `rewardType` | `'item'` or `'cash'` |
| `name` | Inventory item when `rewardType` is `'item'` |
| `count` | Fixed amount. If omitted, rolls `min`–`max` |
| `min` / `max` | Range used when `count` is omitted |
| `metadata` | Optional item metadata |

`cash` pays `bridge.framework.addMoney(src, 'cash', count, 'spooky_season')`. Each interaction rolls **one** row from that pool (`math.random`).

Usable `pumpkin_basket` / `rotten_casket` consume the item after a 5s progress bar, then roll `pumpkin_basket` / `rotten_casket`.
