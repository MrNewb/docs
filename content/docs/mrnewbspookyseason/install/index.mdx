<Callout type="info">
  You need Newb_Bridge, ox_lib, and a framework, inventory and target the bridge supports. Start SpookySeason after all of them. The full list is on [Requirements](/mrnewbspookyseason/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbsSpookySeason` folder in your `resources` folder. Ghost hunts also need [pengu_digiscanner](https://github.com/PenguScript/pengu_digiscanner). Without it, pumpkins, graves, trick-or-treat, shops and crates still run.

### Add the items [step]

There are five required items: `event_token`, `candy_corn`, `chocolate_bar`, `pumpkin_basket` and `rotten_casket`. Register `id_card` too if grave or casket loot should give it. Paste them from [Item setup](/mrnewbspookyseason/install/inventory), then copy the pictures from [Item images](/mrnewbspookyseason/install/inventory-images).

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure qbx_core          # or qb-core / es_extended
ensure ox_inventory      # or your inventory
ensure Newb_Bridge
ensure pengu_digiscanner       # only for ghost hunts
ensure MrNewbsSpookySeason
```

### Configure it [step]

Open `resource/open/shared/config.lua` and `resource/open/server/config.lua` (server-only). Shop prices are counted in `event_token`. Every setting is on [Configuration](/mrnewbspookyseason/install/configuration).

### Restart and check [step]

Restart the server after config or item changes.
