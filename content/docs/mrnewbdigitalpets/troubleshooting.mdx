Find your symptom, then check the right-hand side.

## Install and start-up

| Symptom | Check |
| --- | --- |
| Using the item does nothing | Newb_Bridge started after this resource, the item name does not match, or the item stacks |
| Item has no picture | `digital_pet.png` is not in your inventory's image folder |
| I renamed the item and it broke | Change the name in the inventory **and** in the panel's General page, save, then restart the resource |
| Blank screen after an update | `web/build/` did not upload fully. Replace the whole folder, restart the resource, and clear the FiveM cache if needed |
| No handheld in hand | `stream/` is missing, or an anticheat is deleting the model. See [Anticheat models](/mrnewbdigitalpets/anticheat) |
| DUI mode shows the old screen or a black prop | The game client caches streamed models. After updating `stream/`, restart the resource and fully restart the FiveM client. Also check the Display mode on the Handheld page is DUI and saved |
| Outings or spots never trigger | Capture the position with the panel's position button and keep the radius generous |

## Settings that clash

| What you see | Why it happens |
| --- | --- |
| Trophies, Family or Gift are missing from the toy's menu | They are switched off in `/setupdigitalpets`. Each one hides itself when the server turns it off. About is always there |
| An egg only shows Status | That is correct. An unhatched egg has nothing else to do yet |
| DUI mode freezes the player | That is how it works. In DUI mode the player is frozen with the pose held while the close-up camera is on. Switch Display mode on the Handheld page back to UI if you do not want it |
| The pet ignores a spot or outing you added | Capture the position with the panel's position button, and keep the radius generous |

## Settings that need a restart

Everything in `/setupdigitalpets` applies for every player the moment you press **Save**, with one exception.

| Setting | What to do |
| --- | --- |
| Inventory item name | Rename the item in your inventory **and** on the General page, save, then restart the resource |

Any change you make to the Lua files in the resource folder needs a resource restart.
