- [Newb_Bridge](/newb_bridge) for the framework, inventory, and notifications
- ox_lib
- oxmysql. It stores the setup panel's saved settings in `MrNewb__Settings`, which is created for you
- [Server artifact and OneSync](/getting-started/download#check-your-artifact)
- An inventory Newb_Bridge already supports

Keep the folder named `MrNewb_DigitalPets`. The handheld prop and the UI load by that name.

The pet itself is **not** stored in the database. It lives on the item. The only table is the one that holds your settings.
