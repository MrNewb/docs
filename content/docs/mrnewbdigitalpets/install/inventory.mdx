One item, `digital_pet`.

| Item | Label |
| --- | --- |
| `digital_pet` | Digital Pet |

Copy `digital_pet.png` from `[INSTALL]/IMAGES/` into:

| Inventory | Image folder |
| --- | --- |
| ox_inventory | `ox_inventory/web/images/` |
| qb-inventory / ps-inventory | `html/images/` |
| one_inventory | `one_inventory/web/images/` |

OX is ox_inventory (ESX and Qbox that run ox use this tab). QB is `qb-core/shared/items.lua`. one_inventory needs the PNG in `one_inventory/web/images/` and the item added from the ox_inventory entry.

<Callout type="warning">
  **Required:** set `Config.Inventory = "one_inventory"` in `Newb_Bridge/settings/bridge_resources.lua`. one_inventory provides itself as `ox_inventory` and is not fully compatible with its image paths, so on `"auto"` item images do not load. See [Newb_Bridge configuration](/newb_bridge/configuration).
</Callout>

<Tabs items={['OX', 'QB']} storageKey="inventory-items">
<Tab>

Add to `ox_inventory/data/items.lua`:

```lua
['digital_pet'] = {
    label = 'Digital Pet',
    weight = 500,
    stack = false,
    close = true,
    description = 'A pocket digital pet. Use it to open the Digital Pets toy.',
},
```

</Tab>
<Tab>

Add to your QBCore shared items (`qb-core/shared/items.lua`):

```lua
['digital_pet'] = { name = 'digital_pet', label = 'Digital Pet', weight = 500, type = 'item', image = 'digital_pet.png', unique = true, useable = true, shouldClose = true, description = 'A pocket digital pet. Use it to open the Digital Pets toy.' },
```

</Tab>
</Tabs>
