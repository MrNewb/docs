Copy the PNG from `[INSTALL]/IMAGES/` into your inventory images folder. Filename matches the item name.

| Inventory | Destination |
| --- | --- |
| ox_inventory | `ox_inventory/web/images/` |
| qb-inventory / ps-inventory | `html/images/` |
| one_inventory | `one_inventory/web/images/` |

<Callout type="info">
  **one_inventory:** copy `digital_pet.png` into `one_inventory/web/images/`. Keep the file name as it is. The item itself is imported separately, see [Item setup](/mrnewbdigitalpets/install/inventory#one_inventory).
</Callout>
