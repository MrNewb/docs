# Boss menu (client)

Regular clients don’t load `bridge.bossmenu` — they get a quiet noop table. Open the menu from the [server](/newb_bridge/modules/bossmenu/server).

The host client listens for `Newb_Bridge:client:openBossMenu:<suffix>` (`qbx`, `qb`, `esx`, `vms`, `tk`, `okok`, `codem`, `zat`, `m`) and shows the provider UI.
