# Vehicle keys (server)

The server is the one that actually hands the keys out. Client `give` / `remove` are no-ops on qb / qbx / vehicles_keys / okokGarage — see [client](/newb_bridge/modules/vehiclekeys/client).

## `give(src, vehicle, plate?)`

```lua
give(src, vehicle, plate)
```

| Param | Type |
| ----- | ---- |
| `src` | `number` |
| `vehicle` | `number` |
| `plate` | `string?` |

### Usage Example

```lua
bridge.vehiclekeys.give(source, vehicle)
bridge.vehiclekeys.give(source, 0, plate) -- plate-only providers
```

## `remove(src, vehicle, plate?)`

```lua
bridge.vehiclekeys.remove(source, vehicle, plate)
```

| Param | Type |
| ----- | ---- |
| `src` | `number` |
| `vehicle` | `number` |
| `plate` | `string?` |
