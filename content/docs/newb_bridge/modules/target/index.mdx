Client-only targeting (`ox_target`, `tgiann-target`, `core_focus`, `qb-target`, `sleepless_interact`, `interact`, or `bl_sprites`).

Each option needs a unique `name` and display `label`.

`bl_sprites` is a world-sprite interact, not an eye target. Press **E** on a sprite; one valid option runs immediately, several open an ox_lib context menu. Pin it with `Config.Target = "bl_sprites"` — auto-detect keeps ox_target first if both are installed.

- [Client](/newb_bridge/modules/target/client) — zones, entities, models, `disableTargeting`
- [Server](/newb_bridge/modules/target/server) — not implemented

```lua
bridge.target.addBoxZone({
    name = 'shop_zone',
    coords = vec3(100.0, 200.0, 30.0),
    size = vec3(2, 2, 2),
    rotation = 0,
    options = {
        {
            name = 'open_shop',
            label = 'Open Shop',
            icon = 'fa-solid fa-cart-shopping',
            onSelect = function() end,
        },
    },
})
```
