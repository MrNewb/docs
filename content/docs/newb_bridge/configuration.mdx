Set a value to a resource name if you want to pin it, or leave `"auto"` and it'll grab the first one it finds. `Config.Dispatch` starts on `"internal"`, not `"auto"`.

```lua
Config = {}

Config.Debug = false
Config.VersionCheck = true

Config.Framework = "auto"       -- qbx_core, qb-core, es_extended
Config.Inventory = "auto"       -- ox_inventory, wasabi_inventory, m-Inventory, one_inventory, jaksam_inventory, tgiann-inventory, codem-inventory, core_inventory, origen_inventory, qs-inventory, qb-inventory
Config.Target = "auto"          -- ox_target, tgiann-target, core_focus, qb-target, sleepless_interact
Config.VehicleKeys = "auto"     -- MrNewbVehicleKeys, qbx_vehiclekeys, cd_garage, mVehicle, okokGarage, qb-vehiclekeys, vehicles_keys, wasabi_carlock, Renewed-Vehiclekeys, mk_vehiclekeys, ak47_vehiclekeys, 0r-vehiclekeys
Config.VehicleFuel = "auto"     -- ox_fuel, rcore_fuel, okokGasStation, LegacyFuel, cdn-fuel, lc_fuel, qb-fuel, Renewed-Fuel, ps-fuel, qs-fuelstations, ti_fuel, internal
Config.Menu = "auto"            -- ox_lib, lation_ui, qb-menu
Config.Notifications = "auto"   -- ox_lib, vms_notifyv2, codem-notification, brutal_notify, fl-notify, mythic_notify, okokNotify, pnotify, solaire_notify, t-notify, lation_ui, wasabi_notify, zsx_uiv2, internal
Config.Inputs = "auto"          -- ox_lib, lation_ui
Config.TextUI = "auto"          -- ox_lib, lation_ui, okokTextUI, cd_drawtextui, jg-textui, lab-TextUI, zsx_uiv2
Config.ProgressBar = "auto"     -- ox_lib, lation_ui, wasabi_uikit, progressbar, zsx_uiv2
Config.BossMenu = "auto"        -- qbx_management, qb-management, esx_society, vms_bossmenu, tk_bosstablet, okokBossMenu, codem-bossmenu, zat-bossmenu, m-BossMenu
Config.Dispatch = "internal"    -- or "auto": ps-dispatch, cd_dispatch, tk_dispatch, rcore_dispatch, lb-tablet, origen_police, core_dispatch, kartik-mdt, codem-dispatch, wasabi_mdt, redutzu-mdt

Config.TaskGroups = {
    DefaultMaxPlayers = 8,
    MaxMaxPlayers = 8,
    MinMaxPlayers = 2,
    DefaultImage = '',
    InviteRadius = 10.0,
    JoinCodeLength = 6,
    MaxNameLength = 32,
}
```

<Callout type="warning">
  **Using one_inventory? You must set `Config.Inventory = "one_inventory"`.** Do not leave it on `"auto"`. one_inventory provides itself as `ox_inventory`, so auto-detect treats it as ox_inventory and builds ox_inventory image paths (`nui://ox_inventory/web/images/...`). one_inventory is not fully compatible with those paths, so item images do not load, and shops can fail to open. Pinning it makes the bridge use the one_inventory module and `one_inventory/web/images/`.

  ```lua
  -- Newb_Bridge/settings/bridge_resources.lua
  Config.Inventory = "one_inventory"
  ```

  Restart Newb_Bridge and every script that uses it after changing this.
</Callout>

## Auto-detection

When a setting is `"auto"`, Newb_Bridge walks the list in order and picks the first resource that is `started`. If none are started yet (bridge init can run before dependents), it picks the first whose state is not `"missing"`. If still nothing, it uses the module `fallback` when one exists.

Start order in `server.cfg` matters. Bridged resources should be running before scripts that depend on them. On start, the server console prints one line per module (`auto`, `manual`, or `auto, fallback`).

Provider names and check order: [Supported](/newb_bridge/supported).

## Locales

Newb_Bridge reads the locale ox_lib is already using, so there's nothing to set per script and no locale option of its own. Set `ox:locale` once in `server.cfg` and every resource that uses the bridge follows it:

```cfg
setr ox:locale en
```

Missing codes fall back to `en`. Full list: [Supported](/newb_bridge/supported#locales).

## Configuration examples

### Force a specific inventory

Use when auto-detect picks the wrong resource (for example both `qs-inventory` and `ox_inventory` are present):

```lua
-- Newb_Bridge/settings/bridge_resources.lua
Config.Inventory = "ox_inventory"
Config.Framework = "qbx_core"
Config.Target = "ox_target"
Config.Notifications = "ox_lib"
```
