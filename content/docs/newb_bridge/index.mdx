## Start order

```cfg
ensure ox_lib
ensure oxmysql
ensure Newb_Bridge
ensure MrNewb_YourScript
```

Use the [latest release](https://github.com/MrNewb/Newb_Bridge/releases/latest), not the source zip from the main page (the UI isn't built there). Keep the folder named `Newb_Bridge`.

Leave providers on `"auto"` unless you need to pin one. **The exception is one_inventory: you must set `Config.Inventory = "one_inventory"` yourself.** It provides itself as `ox_inventory`, so auto-detect picks the ox_inventory module and its image paths. See [Configuration](/newb_bridge/configuration). Dispatch defaults to `"internal"`. Inventories, targets, keys, fuel, and the rest are on [Supported](/newb_bridge/supported). `one_inventory` is on that inventory list. Details: [Configuration](/newb_bridge/configuration), [Modules](/newb_bridge/developers/modules). Writing your own resource? See [For Developers](/newb_bridge/developers).
