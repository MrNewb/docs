## Start order

```cfg
ensure ox_lib
ensure oxmysql
ensure Newb_Bridge
ensure MrNewb_YourScript
```

Use the [latest release](https://github.com/MrNewb/Newb_Bridge/releases/latest), not the source zip from the main page (the UI isn't built there). Keep the folder named `Newb_Bridge`.

Leave providers on `"auto"` unless you need to pin one. Dispatch defaults to `"internal"`. Details: [Configuration](/newb_bridge/configuration), [Modules](/newb_bridge/developers/modules). Writing your own resource? See [For Developers](/newb_bridge/developers).
