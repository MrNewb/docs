## Start order

Start Newb_Bridge after ox_lib, oxmysql, your framework, inventory and target, and before any script that uses it. Full example: [Installation](/newb_bridge/getting-started).

Leave providers on `"auto"` unless you need to pin one. The one exception is `one_inventory`, which must be pinned (see [Configuration](/newb_bridge/configuration)).
