You only need this section if you're writing code against Newb_Bridge. Running the scripts needs nothing past [Installation](/newb_bridge/getting-started) and [Configuration](/newb_bridge/configuration).

## Import the bridge

Each resource that calls `bridge.*` pulls it in from its own `fxmanifest.lua`:

```lua
shared_scripts {
    '@ox_lib/init.lua',
    '@Newb_Bridge/import.lua',
    -- your shared scripts
}

dependencies {
    'ox_lib',
    'Newb_Bridge',
}
```

That gives your resource the global `bridge` table and the resolved `Config`. A module is loaded the first time you touch it (`bridge.inventory`, `bridge.menu`, and so on), while the host preloads every configured provider when it starts. Your resource has to start **after** Newb_Bridge, since `import.lua` errors when the bridge isn't running.
