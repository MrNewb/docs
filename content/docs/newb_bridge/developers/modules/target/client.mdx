# Target (client)

Client-only targeting (`ox_target`, `tgiann-target`, `core_focus`, `qb-target`, `sleepless_interact`, `interact`, or `bl_sprites`).

Each option needs a unique `name` and display `label`.

No [server](/newb_bridge/developers/modules/target/server) implementation.

## Zones

### `addBoxZone(payload)`

```lua
addBoxZone(payload)
```

| Param | Type |
| ----- | ---- |
| `payload` | [TargetBoxZone](#targetboxzone) |

| **Returns** | `number` \| `string` — zone id |

### Usage Example

```lua
bridge.target.addBoxZone({
    name = 'shop_zone',
    coords = vec3(100.0, 200.0, 30.0),
    size = vec3(2, 2, 2),
    rotation = 0,
    options = {
        {
            name = 'open_shop',
            label = 'Open Shop',
            icon = 'fa-solid fa-cart-shopping',
            onSelect = function() end,
        },
    },
})
```

### `addSphereZone(payload)`

```lua
addSphereZone(payload)
```

| Param | Type |
| ----- | ---- |
| `payload` | [TargetSphereZone](#targetspherezone) |

| **Returns** | `number` \| `string` — zone id |

### Usage Example

```lua
bridge.target.addSphereZone({
    name = 'atm_zone',
    coords = vec3(0, 0, 0),
    radius = 1.5,
    options = { { name = 'use_atm', label = 'Use ATM', onSelect = function() end } },
})
```

### `removeZone(zoneId)`

| Param | Type |
| ----- | ---- |
| `zoneId` | `string` \| `number` |

```lua

```
