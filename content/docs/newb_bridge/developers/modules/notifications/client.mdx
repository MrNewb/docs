# Notifications (client)

Show a notification on the local player. Server scripts use [notify(src, data)](/newb_bridge/developers/modules/notifications/server). Payload type: [OxNotification](/newb_bridge/developers/modules/notifications#oxnotification).

## `notify(data)`

```lua
notify(data)
```

| Param | Type |
| ----- | ---- |
| `data` | [OxNotification](/newb_bridge/developers/modules/notifications#oxnotification) |

Each client `notify` also fires `Newb_Bridge:Client:NotifyShown` (used by the pause-menu history).

### Usage Example

```lua
bridge.notifications.notify({
    title = 'Success',
    description = 'Item used',
    type = 'success',
    duration = 4000,
})
```
