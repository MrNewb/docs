# Dialogue (client)

Client-only NUI dialogue system. Access via `bridge.dialogue` (lazy) or `exports.Newb_Bridge:Dialogue()`. Accessing this module on the [server](/newb_bridge/developers/modules/dialogue/server) throws.

## `RegisterMenu(menu)`

```lua
RegisterMenu(menu)
```

| Param | Type |
| ----- | ---- |
| `menu` | [DialogueMenu](#dialoguemenu) |

| **Returns** | `string` — menu id |

### Usage Example

```lua
local id = bridge.dialogue.RegisterMenu({
    id = 'beekeeper',
    title = 'Beekeeper',
    text = 'Need supplies?',
    options = {
        { title = 'Buy jar', onSelect = function() end },
        { title = 'Sell honey', onSelect = function() end },
    },
})
```

## `OpenMenu(id, target?)`

```lua
OpenMenu(id, target)
```

| Param | Type | Description |
| ----- | ---- | ----------- |
| `id` | `string` | Registered menu id |
| `target` | `number` \| `vector3` \| `vector4` \| [DialogueTargetOptions](#dialoguetargetoptions)? | Ped entity or world position |

Fails silently if the player is too far from the target.

### Usage Example

```lua
bridge.dialogue.OpenMenu('beekeeper', shopPed)

bridge.dialogue.OpenMenu('beekeeper', {
    ped = shopPed,
    maxDistance = 3.0,
    camFov = 40.0,
})
```

## Types

### `DialogueMenu`

| Field | Type |
| ----- | ---- |

### `DialogueOption`

| Field | Type |
| ----- | ---- |
| `title` | `string?` |
| `description` | `string?` |
| `input` | `DialogueInputField?` |
| `disabled` | `boolean?` |
| `readOnly` | `boolean?` |
| `item` | `string` \| `{ item, count?, metadata? }?` | Hidden unless `bridge.inventory.hasItem` passes when the menu is built |
| `menu` | `string?` | Child menu id (only menus linked this way, or via `menu` parent / stack, are navigable) |
| `onSelect` | `fun(args: any)?` |
| `event` | `string?` | Client event name |
| `serverEvent` | `string?` | Server event; consumer handlers must still validate distance/job/etc. |
| `type` | `'info'` \| `'error'` \| `'success'` \| `'warning'` |

### `DialogueInputField`

Inline input on a `DialogueOption` (`option.input`).

| Field | Type |
| ----- | ---- |
| `type` | `'input'` \| `'number'` \| `'checkbox'` \| `'select'` \| `'multi-select'` \| `'slider'` \| `'textarea'` |
| `label` | `string` |
| `description` | `string?` |
| `placeholder` | `string?` |
| `icon` | `string?` |
| `required` | `boolean?` |
| `disabled` | `boolean?` |
| `default` | `any?` |
| `password` | `boolean?` — `input` only |
| `min` / `max` | `number?` — numeric types, or textarea row count |
| `options` | `{ value, label?, description? }[]?` — `select` / `multi-select` |
