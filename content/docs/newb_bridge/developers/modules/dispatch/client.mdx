# Dispatch (client)

Regular clients don’t load `bridge.dispatch` — they get a quiet noop table. Send alerts from the [server](/newb_bridge/developers/modules/dispatch/server).

The host client listens for `Newb_Bridge:dispatch:internalAlert` and draws a temporary blip + notification when `Config.Dispatch` is `"internal"`.
