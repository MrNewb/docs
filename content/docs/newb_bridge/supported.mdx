## Inventory

`ox_inventory`, `wasabi_inventory`, `m-Inventory`, `one_inventory`, `jaksam_inventory`, `tgiann-inventory`, `codem-inventory`, `core_inventory`, `origen_inventory`, `qs-inventory`, `qb-inventory`. Set `qb-framework` or `esx-framework` in `Config.Inventory` when you want the framework's built-in items. Those two have no stashes, shops, or hooks.

<Callout type="warning">
  **one_inventory must be set manually.** Put `Config.Inventory = "one_inventory"` in `Newb_Bridge/settings/bridge_resources.lua`. one_inventory provides itself as `ox_inventory`, so on `"auto"` the bridge treats it as ox_inventory and uses ox_inventory image paths, which one_inventory does not fully support. See [Configuration](/newb_bridge/configuration).
</Callout>

## Dispatch

Default is `"auto"`. The first started resource from this list wins, and `internal` (blips and notifications built into the bridge) is used when none is installed: `ps-dispatch`, `cd_dispatch`, `tk_dispatch`, `rcore_dispatch`, `lb-tablet`, `origen_police`, `core_dispatch`, `kartik-mdt`, `codem-dispatch`, `wasabi_mdt`, `redutzu-mdt`.

<ProviderTable group="dispatch" />
