**Exclusively for ox_inventory.** No other inventory is supported, and there is no ESX / QBCore / Qbox variant. Runs on [Newb_Bridge](/newb_bridge/getting-started).

Unlike the rest of my scripts, the items here call ox_inventory's `server.export` directly.

[GitHub](https://github.com/MrNewb/MrNewbWeaponTints) · [Discord](https://discord.gg/mrnewbscripts) · [Configuration](/mrnewbweapontints/install/configuration) · [Exports](/mrnewbweapontints/exports)

## Features

- Seven vanilla weapon tints as usable items (`greentint` … `platinumtint`)
- `newbserialfile` writes a filed-off serial onto the equipped weapon
- MK2 weapons remap `server.tint` through a built-in index table
- ox_inventory metadata (`tint`, `weapontint`, `serial`) — no SQL, no config file
