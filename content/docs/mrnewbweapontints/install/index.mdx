<Callout type="info">
  WeaponTints needs ox_inventory, plus Newb_Bridge and ox_lib. Start it after all three, and keep the folder named `MrNewbWeaponTints`. The full list is on [Requirements](/mrnewbweapontints/requirements).
</Callout>

### Unzip it [step]

Put the `MrNewbWeaponTints` folder in your `resources` folder. No other inventory is supported.

### Add the items [step]

Paste every item from [Item setup](/mrnewbweapontints/install/inventory) into `ox_inventory/data/items.lua`, then copy the pictures from [Item images](/mrnewbweapontints/install/inventory-images) into `ox_inventory/web/images/`.

Each item has to include `server.export` and `allowArmed = true`. The export is what makes the item do something, and `allowArmed` lets a player use it with a weapon out.

| Item | `server.export` |
| --- | --- |
| `greentint` to `platinumtint` | `'MrNewbWeaponTints.setweapontint'` |
| `newbserialfile` | `'MrNewbWeaponTints.newbserialfile'` |

Tint items also set `server.tint` from 1 to 7. MK2 weapons are remapped for you.

<Callout type="info">
  **On Kora Framework:** WeaponTints does not work on it. Its items rely on ox_inventory features that `kora_inventory` does not run, so use ox_inventory for this resource.
</Callout>

### Add it to server.cfg [step]

```cfg
ensure ox_lib
ensure ox_inventory
ensure Newb_Bridge
ensure MrNewbWeaponTints
```

### Restart and check [step]

Restart the server after item, picture or locale changes, so ox_inventory reloads `items.lua`. WeaponTints has no config file, because names, tints and exports all live in the item definitions.
